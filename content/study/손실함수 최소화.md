딥러닝 모델 훈련의 핵심
손실함수를 최소화 하는 파라미터가 궁극적인 목적
$$\min_\theta L(\theta)$$
# Gradient Descent
$$\theta^{(i+1)}=\theta^{(i)}-\alpha\nabla L(\theta^{(i)})$$
   랜덤한 최초 위치에서 시작해 gradient가 0이 될때까지 업데이트
   + 배치 경사하강법 : 모든 데이터를 이용
   + Stochastic 경사하강법 : 하나의 샘플을 이용
   + Mini-batch 경사하강법 : 소수의 샘플을 이용
  하이퍼 파라미터인 학습률을 정하기 어렵다

## a. Stochastic Gradient Descent 확률적 경사하강법
- 일반 경사하강법은 한 스텝마다 그라디언트 계산에 계산량을 많이 쓴다
- SGD는 하나의 데이터만을 사용해 경사를 계산해 계산량을 줄임
- 각 스텝은 부정확하지만 결국 비슷하게 수렴, 그래서 빠르다
- 부정확해서 파라미터 업데이트는 더 많이 할 수도 있음
$$\text{Ordinary }\nabla L=-\sum^n_{i=1}2x_i(y_i-wx_i-c)$$
$$\text{Stochastic }\nabla L=-2x_i(y_i-wx_i-c)$$

## b. Mini-batch
batch 란 훈련에 사용되는 데이터 셋 하나의 단위

일반적 방법에선 파라미터 업데이트 한 번에 전체 배치를 사용

SGD 에서는 데이터 하나로 파라미터 업데이트

Mini-batch에서는 전체 훈련집합을 여러 집합으로 분할, 파라미터를 미니배치 하나마다 업데이트

## c. Learning Rate 학습률, $\alpha$
얼마나 빨리 파라미터를 업데이트 할 지 결정
Hessian 의 크기가 학습률의 최대치
- 큰$\alpha$ : 빠르지만 불안정한 학습, 수렴 안할수도 있음
- 작은 $\alpha$ : 느리지만 안정적인 학습

# Momentum Optimizer
$$m^{(i)}=\beta_1m^{(i-1)}+(1-\beta_1)\nabla L(\theta^{(i)})$$
$$\theta^{(i+1)}=\theta^{(i)}-\alpha m^{(i)}$$
관성계수를 추가해 gradient를 업데이트
Local minimum 문제를 해결
관성에 의해 더 빠른 학습 가능

# Adaptive Gradient (Adagrad)
$$g_k^{(i)}=g_k^{(i-1)}+\nabla_kL(\theta^{(i)})^2$$
$$\theta_k^{(i+1)}=\theta_k^{(i)}-{\alpha \over \sqrt{g_k^{(i)}+\epsilon}}\nabla_kL(\theta^{(i)})$$
일반적인 GD는 학습률이 모두 같음
변화가 적은 파라미터엔 더 큰 학습률을, 변화가 많은 파라미터는 작은 학습률을 적용

# RMSProp
$$g_k^{(i)}=\beta g_k^{(i-1)}+(1-\beta)\nabla_kL(\theta^{(i)})^2$$
$$\theta_k^{(i+1)}=\theta_k^{(i)}-{\alpha \over \sqrt{g_k^{(i)}+\epsilon}}\nabla_kL(\theta^{(i)})$$
Adagrad는 학습률이 점차 작아져 학습이 진행되지 않는 문제가 있었음
$g_k^{(i)}$계산에 이동평균을 적용하여 0으로 빠르게 떨어지는것을 방지

# Adam (Adaptive Momentum Estimation)
$$m_k^{(i)}=\beta_1m_k^{(i-1)}+(1-\beta_1)\nabla L(\theta^{(i)})$$
$$g_k^{(i)}=\beta_2 g_k^{(i-1)}+(1-\beta_2)\nabla_kL(\theta^{(i)})^2$$
$$\theta_k^{(i+1)}=\theta_k^{(i)}-{\alpha \over \sqrt{g_k^{(i)}+\epsilon}}m_k^{(i)}$$
Momentum + RMSProp
Momentum으로 빠르고 지속적인 업데이트
RMSProp으로 파라미터 별 차등적인 업데이트

# Learning Rate Decay
최적화가 진행될수록 결국 학습률은 작아져야 함
학습에 따라 학습률을 점차 작아지게하는 방식

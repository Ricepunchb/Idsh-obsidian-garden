## K-means
군집화 알고리즘 중 partitioning-based

**WCV** (군집 내 분산, Within-cluster variance)
Centroid (군집의 중심점) := $\mu_k = \dfrac{1}{|C_k|}\sum_{i\in C_k}x_i$
$$\text{WCV} = \dfrac{1}{|C_1|}\sum_{i\in C_1}\|x_i-\mu_i\|^2+\cdots+\dfrac{1}{|C_k|}\sum_{i\in C_k}\|x_i-\mu_i\|^2$$
k-means는 WCV를 최소화 하는 알고리즘
optimal solution이 아닌 sub-optimal solution을 찾음
초기 상태는 무작위로 배정되기 때문에 할때마다 결과가 다를 수 있음 그래서 보통 여러번 시도함

튜닝 파라미터는 **군집의 개수** 
- 많은 군집의 개수 : WCV가 낮음, 재현성이 낮음, 설명 어려움
- 적은 군집의 개수 : WCV가 높음, 재현성이 높음, 설명이 쉬움

군집의 개수는 어떻게 결정하는가?
해석이 용이하게 선택하거나, 체계적으로 특정 방법을 통해 선택
- Elbow method : WCV를 많이 감소시키지 않는 적절한 k를 선택

# Gaussian Mixture
k-means 의 일반화 혹은 soft-clustering이라고도 부름
**mixture model** : 표본이 특정 분포를 갖는 군집들에서 생성되었다고 가정. 보통 정규분포를 가졌다고 가정함

Example case.
1. 표본이 군집 $C_1$, 군집 $C_2$ 에서 생성되었다고 가정.
2. 표본 $i$를 관측할 확률은 $P(x_i)=P(x_i|x_i\in C_1)P(x_i\in C_1)+P(x_i|x_i\in C_2)P(x_i\in C_2)$
3. 정규 분포에 의해, $P(x_i|x_i\in C_1) = \dfrac{1}{\sigma_1\sqrt{2\pi}}\exp\left[-\dfrac{(x_i-\mu_1)^2}{2\sigma_1^2}\right]\sim N(\mu_1,\sigma_1^2)$
4. 일반적으로, k개 군집에 대해 $\displaystyle P(x_i)=\sum^k_{t=1}P(x_i|x_i\in C_t)P(x_i\in C_t)=\sum^k_{t=1}\dfrac{1}{\sigma_t\sqrt{2\pi}}\exp\left[-\dfrac{(x_i-\mu_t)^2}{2\sigma_t^2}\right]\cdot\pi_t$

$k=1,2,...,K$ 군집에 대해 $\mu_k, \sigma_k, \pi_k$를 찾는것이 목표
Maximum likelihood를 이용
Likelihood : $\displaystyle = \prod^n_{i=1}P(x_i)=\prod^n_{i=1} \sum^K_{k=1}\dfrac{1}{\sigma_k\sqrt{2\pi}}\exp\left[-\dfrac{(x_i-\mu_k)^2}{2\sigma_k^2}\right]\cdot\pi_k$

최대 우도 기법
- 우도는 파라미터에 따라 다름
- 현재 데이터는 가장 우도가 높은 데이터
- 우도를 최대화하는 파라미터가 최적의 파라미터

보통 우도의 로그값을 최대화
EM기법을 활용함

## Expectation-Maximization 알고리즘

1.  $\mu_k, \sigma_k, \pi_k$ 를 초기화

2. E-step : $$P(x_i|x_i\in C_k)=\dfrac{1}{\sigma_k\sqrt{2\pi}}\exp\left[{-\dfrac{(x_i-\mu_k)^2}{2\sigma_k^2}}\right] $$
3. M-step : $$\max_{\mu_k,\sigma_k,\pi_k}\sum^n_{i=1}\log\left[{\dfrac{1}{\sigma_k\sqrt{2\pi}}\exp\left[{-\dfrac{(x_i-\mu_k)^2}{2\sigma_k^2}}\right]\cdot\pi_k}\right]_{x_i\in C_k}$$
$$
\mu_k=\frac{1}{\left|C_k\right|} \sum_{i \in C_k} x_i \quad \sigma_k^2=\frac{1}{\left|C_k\right|-1} \sum_{i \in C_k}\left(x_i-\mu_k\right)^2 \quad \pi_k=\frac{\left|C_k\right|}{n}
$$
4. 수렴할때까지 반복


# Hierarchical Clustering
계층적 군집화.
군집 사이에 계층구조가 형성되있음. 나무 모양의 덴드로그램으로 표현
- 병합형 군집화 : 아래에서 위로 합쳐가는 것
- 분리형 군집화 : 위에서 아래로 분리해 나가는 것

binary 트리랑 비슷하게 생김. 위에서 적당히 잘라서 k개 군집을 만듦.

## Linakge
군집과 군집 사이의 거리 측정 metric
- Complete : 각 군집 표본들 간의 최대 거리
- Single : 각 군집 표본들 간의 최소 거리
- Average : 각 군집 표본들 간의 평균 거리
- Centroid : 각 군집 중심점 간의 거리

거리는 데이터와 목적에 따라 측정법이 다름
- 유클리드 거리
- 맨하탄 거리
- 상관 계수
- 코사인 거리

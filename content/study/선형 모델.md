# 1. 선형 모델 (Linear model)

실제 $f$가 선형성을 갖고 있다는 전제에서 출발.

-  **회귀 (Regression)**
Y가 수치형 변수인 수명, 월급, 주가 등 숫자형 일때

- **분류(Classification)**
Y가 범주형 변수인 성공/실패, 자동차 종류, 꽃 품종 등 일때

## 선형 회귀 모델 (Linear Regression)

 선형 회귀 모델은 회귀 문제에 적용한다.
 
### 단순 선형 회귀 (Simple Linear Regression)

하나의 독립변수 X와 하나의 출력변수 Y에 대한 모델
$$ w_1X + w_2 \approx Y$$
우리는 이 $w_1, w_2$ 를 찾는것이 목표.

처음 $\hat{w_1}X + \hat{w_2} = \hat{f}(X)$ 라고 설정
그러면, $\hat{y} = \hat{w_1}x+\hat{w_2}$  을 각 샘플에 대해 얻을 수 있음.
여기에 MSE (Mean Square Error) $\displaystyle\frac{1}{n}\sum^n_{i=1}(y_i-\hat{f}(x_i))^2$ 를 Error Metric으로 정하고,
손실함수 (Loss function)을 $$L(\hat{w_1}, \hat{w_2}) = \sum^n_{i=1}e_i^2 = \sum^n_{i=1}(y_i - \hat{w_2} - \hat{w_1}x_i)^2 $$ 으로 정하면 이 함수를 미분하여, 
$$\begin{align} &\hat{w_1} = {\sum^n_{i=1}(x_i-\bar{x})(y_i-\bar{y}) \over \sum^n_{i=1}(x_i-\bar{x})^2} \\ & \hat{w_2} = \bar{y}-\hat{w_1}x \end{align}$$
로 모델의 에러를 최소화. 하지만 이 과정은 Train 데이터 샘플에 대한 최소화이므로 Eval 데이터 샘플에 대한 에러의 최소화를 보장하지는 않음!

### 일반 선형 회귀 (Multiple Linear Regression)

여러 입력 변수와 하나의 출력 변수 $\displaystyle w_0 + w_1X_1 + w_2X_2 + \cdots + w_nX_n \approx Y$ 형태.

Loss는 Square-error로 측정
$$L=\sum^n_{i=1}(y_i-\hat y_i)^2$$
각 $X_i$는 독립적으로 $\hat y_i$에 기여함

## 모델의 평가
모델이 얼마나 좋은 성능을 냈는지 평가하는 척도
### Mean Square Error
$$MSE = \dfrac{1}{n}\sum^n_{i=1}(y_i-\hat f(x_i))^2$$
### 결정계수 $R^2$
Y가 X에 의해 얼마나 설명되는지에 대한 비율
0과 1사이 값을 갖는데 모델이 아주 나쁜 경우 음수가 나옴
$$R^2=1-{\sum^n_{i=1}(y_i-\hat y_i)^2 \over \sum^n_{i=1}(y_i-\bar y_i)^2}=1-{\text{unexplained variance} \over\text{total variance of Y}}$$

입력 변수가 범주형 변수일 경우, 그 변수는 가변수로 변환하여 모델링
예) 남성 = 1, 여성 = 0

## 상호작용의 고려
변수가 독립적이지 않으면, 
$$Y\approx w_0+w_1X_1+w_2X_2+w_3X_1X_2$$ 이런식이 나올수있다
상호작용 항 $X_1X_2$를 새로운 변수 $X_3$처럼 취급한다

# 2. 로지스틱 회귀 모델
대부분의 분류 문제는 $Y$를 직접 예측하기보다는 $Y$일 확률을 예측함

## Logistic Regression
클래스에 대한 확률을 시그모이드 함수를 이용해 모델링
Binary Classification 이라는 전제 하에,
$$\sigma(t)=\dfrac{e^t}{1+e^t}={1 \over 1+e^{-t}} \quad\text{ Sigmoid Function}$$
$$\Pr[Y=1|X]=\sigma(\hat f(X))={1\over1+e^{-(w_0+w_1X_1\cdots)}}$$
$$\Pr[Y=0|X]=1-\Pr[Y=1|X]$$
### 우도 Likelihood
어떤 모델을 가정했을 때 현재 데이터를 관측할 확률
$$l=\prod_{i:y_i=0}\Pr[Y=0|X]\prod_{i:y_i=1}\Pr[Y=1|X]$$
**최대우도법** : 우도를 가장 크게 만드는 파라미터를 찾는것. 보통 우도의 로그값을 최대화하면서 찾음

## 분류모델 평가

| |실제 Pos|실제 Neg|
|---|---|---|
|예측 Pos|A|B|
|예측 Neg|C|D|

- **정확도** (Accuracy) : 각 클래스를 정확히 맞춘 비율
$$Acc=\dfrac{1}{n}\sum^n_{i=1}I(y_i\ne\hat f(x_i))$$

$$= {\text{A+D}\over\text{A+B+C+D}}$$
- **재현율** (Recall) : 실제 맞는것들 중 맞다고 예측된 것들의 비율
$${\text{A}\over\text{A+C}}$$
- **정밀도** (Precision) : 맞다고 예측한 것들 중 실제 맞는것들 비율
$${\text{A}\over\text{A+B}}$$
- **위양성률** (False Positive Rate) : 실제 아닌것들 중 맞다고 예측된 것들의 비율
$${\text{B}\over\text{B+D}}$$

- **F1 Score** := $2\cdot\dfrac{\text{정밀도}\times\text{재현율}}{\text{정밀도+재현율}} = \dfrac{A}{A+{B+C\over2}}$

# 1. Identity function
   $$\sigma(z)=z$$

# 2. Sigmoid function
   $$\sigma(z)=\dfrac{1}{1+e^{-z}}$$
   기본적인 활성화 함수
   vanishing gradient의 문제가 있음
   결과값이 항상 양수

# 3. Hyperbolic tangent
   $$\sigma(z)=\dfrac{e^z-e^{-z}}{e^z+e^{-z}}$$
   모양은 sigmoid와 비슷한데 중심이 0이다
   양수 음수가 모두 나와 편향되지 않는다
   vanishing gradient 의 가능성이 적지만 존재는 함

# 4. ReLU (Rectifier Linear Unit)
   $$\sigma(z)=\max(0,z)$$
   일반적으로 가장 많이 이용되는 함수
   계산이 효율적이고 vanishing gradient 가 적다
   희소표현이 가능
   양수만 도출됨
   값 제한이 없음
   잘못하면 모든 gradient 가 0이됨

# 5. Leaky ReLU
   $$\sigma(z)=\max(\alpha z,z)$$
   ReLU를 보완하기 위한 변형함수
   gradient가 0이 되는걸 방지

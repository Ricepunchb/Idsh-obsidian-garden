# Perceptron
인간의 뉴런을 본뜬 수학적 모델 : Linear Model + Not Linear Model
$$y=\sigma(W^TX+b)$$
이 퍼셉트론을 1계층으로 삼고, 이것을 많이 쌓을수록 더 복잡한 판단 경계를 수립 가능함

다계층의 퍼셉트론을 MLP라 하며 잠재계층이 두 개 이상인 신경망을 DNN 즉, 심층 신경망이라고 함

# MLP

각 레이어에서 파라미터의 갯수는 $(\text{현재 노드 갯수}+1)\times\text{다음 노드 갯수}$
ex. 입력변수 5개, 은닉층 노드 4개, 결과 노드 2개면
$(5+1)\times4+(4+1)\times2=34$

# 배치(Batch) 처리와 행렬 곱

실제로는 데이터를 하나씩이 아니라 $m$개씩 배치로 묶어서 처리한다. 입력을 행렬 $X\in\mathbb R^{m\times n_\text{in}}$로 쌓고(각 행이 샘플 하나), 가중치를 $W\in\mathbb R^{n_\text{in}\times n_\text{out}}$(각 열이 뉴런 하나로 가는 가중치)로 두면 레이어 전체가 한 번의 행렬 곱으로 계산된다.
$$H=f(XW+\mathbf b)$$
여기서 $\mathbf b\in\mathbb R^{n_\text{out}}$은 $m\times n_\text{out}$ 모양으로 broadcast된다.

>[!tip] PyTorch에서의 관례
>수학 표기로는 $W$를 $n_\text{in}\times n_\text{out}$으로 쓰지만, PyTorch의 `nn.Linear`는 내부적으로 $W$를 $n_\text{out}\times n_\text{in}$ 모양으로 저장하고, forward pass에서 `X @ W.T`를 계산한다. 이 transpose는 stride만 바꾸는 연산이라 비용이 거의 없고, 이렇게 하면 $W$에 대한 gradient가 자연스럽게 $W$와 같은 모양($n_\text{out}\times n_\text{in}$)으로 나온다.

## Backpropagation of a Linear Layer

$Z=XW+b$에 대해 역전파를 유도하면 다음과 같다(수학 표기, $W\in\mathbb R^{n_\text{in}\times n_\text{out}}$ 기준).
$$
\frac{\partial L}{\partial X}=\frac{\partial L}{\partial Z}W^\top\quad (m,n_\text{out})\times(n_\text{out},n_\text{in})=(m,n_\text{in})
$$
$$
\frac{\partial L}{\partial W}=X^\top\frac{\partial L}{\partial Z}\quad (n_\text{in},m)\times(m,n_\text{out})=(n_\text{in},n_\text{out})
$$
같은 bias $\mathbf b$가 배치의 모든 샘플에 더해지므로, 각 샘플이 만든 gradient가 배치 차원에 대해 합산된다.
$$
\frac{\partial L}{\partial b_j}=\sum_{i=1}^m\frac{\partial L}{\partial z_{ij}}
$$

직관: 배치가 없는 단일 샘플이라면 $\partial L/\partial X$는 그냥 $\partial L/\partial Z \cdot W^\top$이다. 배치가 있어도 각 행 $i$는 $X$의 행 $i$에만 의존하므로(샘플끼리 상호작용 없음), 단일 샘플의 gradient를 행마다 쌓기만(stack) 하면 된다.
- 일반적으로: 텐서가 배치 전체에서 공유되면($W$처럼) 배치 차원이 sum-out되며 gradient는 **contract**(배치 차원이 안쪽에 오는 행렬곱), 공유되지 않으면($X$처럼) 배치 차원이 그대로 보존되며 gradient는 **stack**된다.

PyTorch 구현처럼 $Z=XW^\top$ (즉 $W\in\mathbb R^{n_\text{out}\times n_\text{in}}$)이라면 식이 아래처럼 바뀐다.
$$
\frac{\partial L}{\partial X}=\frac{\partial L}{\partial Z}W,\qquad \frac{\partial L}{\partial W}=\left(\frac{\partial L}{\partial Z}\right)^\top X
$$

더 일반적인 gradient/Jacobian/chain rule 이론과 computation graph 기반 backprop 메커니즘은 [[Gradients and Backpropagation]] 참고.

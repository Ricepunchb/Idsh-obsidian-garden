# Perceptron
인간의 뉴런을 본뜬 수학적 모델 : Linear Model + Not Linear Model
$$y=\sigma(W^TX+b)$$
이 퍼셉트론을 1계층으로 삼고, 이것을 많이 쌓을수록 더 복잡한 판단 경계를 수립 가능함

다계층의 퍼셉트론을 MLP라 하며 잠재계층이 두 개 이상인 신경망을 DNN 즉, 심층 신경망이라고 함

# MLP

각 레이어에서 파라미터의 갯수는 $(\text{현재 노드 갯수}+1)\times\text{다음 노드 갯수}$
ex. 입력변수 5개, 은닉층 노드 4개, 결과 노드 2개면
$(5+1)\times4+(4+1)\times2=34$

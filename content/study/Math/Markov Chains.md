> [!info] [[Markov Decision Process|Markov Decision Process (MDP)]]와는 다른 개념
> MDP는 에이전트가 행동을 선택해 보상을 최대화하는 강화학습 프레임워크다. 여기서 다루는 **Markov chain**은 행동(action)도 보상(reward)도 없이, 그냥 상태가 확률적으로 흘러가는 과정 자체를 다룬다 — MDP에서 정책(policy)을 고정해버리면 남는 것이 바로 Markov chain이다.

# 1. 개요

**Markov chain**은 상태공간 $S$ 위를 움직이는 random variable의 수열 $X_0,X_1,X_2,\dots$ 로, **Markov 성질**(미래는 오직 현재 상태에만 의존하고 과거 경로와는 무관하다)을 만족한다.

# 2. 전이행렬 (Transition matrix)

유한 상태공간에서는 체인 전체가 **전이행렬** $P$ 하나로 결정된다.
$$P_{ij}=P(X_{t+1}=j \mid X_t=i)$$

- 각 행은 "지금 상태 $i$에서 다음에 어디로 갈지"에 대한 확률분포이므로 행의 합은 항상 $1$이다.
- 시점 $t$에서의 상태 분포를 $\pi_t$ (행벡터)라 하면, 한 스텝 뒤의 분포는 단순 행렬곱이다.
$$\pi_{t+1}=\pi_tP$$

# 3. 정상분포 (Stationary distribution)

>[!attention] Definition
>$$\pi=\pi P$$
>를 만족하는 분포 $\pi$를 **stationary distribution**이라 한다. 약한 조건 하에서 체인은 유일한 정상분포를 가지며, 시작 상태와 무관하게 $\pi_t\to\pi$로 수렴한다.

정상분포는 "장기적으로 각 상태에 머무는 시간 비율"로 해석할 수 있다. 이로부터 바로 유용한 공식이 하나 나온다.

>[!tip] 기대 복귀 시간
>$$E[\text{상태 } i \text{로 돌아오는 데 걸리는 시간}]=\dfrac{1}{\pi_i}$$
>자주 방문하는 상태($\pi_i$가 큼)일수록 다시 돌아오는 데 걸리는 시간이 짧다는 직관과 일치한다.

# 4. 흡수 시간·흡수 확률 구하기 (First-step analysis)

체인에 "빠지면 못 나오는" **흡수 상태(absorbing state)**가 있을 때, 특정 상태에서 시작해 흡수되기까지 걸리는 기대 시간이나 특정 흡수 상태에 도달할 확률을 구하는 문제가 자주 나온다. 풀이 원리는 [[Probability Problem Types|first-step analysis]]와 동일하다 — "한 스텝만 진행한 뒤, 남은 문제를 자기 자신으로 재귀적으로 표현한다."

>[!attention] 흡수까지 걸리는 기대 시간
>목표 흡수상태를 $A$라 하면 $h_A=0$이고, 나머지 상태 $i$에 대해
>$$h_i=1+\sum_jP_{ij}h_j$$
>(한 스텝을 쓰고, 다음 상태 $j$에서부터 다시 $h_j$만큼 걸린다는 재귀식)

>[!attention] 특정 흡수상태에 도달할 확률
>원하는 흡수상태를 $A$, 다른 흡수상태들을 $B$라 하면 $q_A=1,\,q_B=0$이고,
>$$q_i=\sum_jP_{ij}q_j$$

**풀이 절차**
1. 위 재귀식을 first-step analysis로 세운다.
2. 상태 수가 적으면 연립방정식을 직접 푼다.
3. 체인에 구조(대칭성, 규칙성)가 있으면 작은 경우부터 계산해 패턴을 추측하고, 함수 형태를 가정한 뒤 경계조건에 맞춰 검증한다.

# 5. 유용한 테크닉

- **대칭성으로 상태 축소**: 예를 들어 원(cycle) 위의 random walk라면, 각 상태 자체가 아니라 "목표까지의 거리"로 재매개변수화하면 상태 수를 확 줄일 수 있다.
- **정상분포로 지름길 찾기**: 모든 노드가 똑같이 생긴 그래프(사이클, 완전그래프 등)에서 인접한 두 노드 사이의 기대 도달시간 $h$는 항상 $n-1$이다 ($n$ = 노드 수). 정상분포가 모든 상태에서 $1/n$로 균등하므로 $E[\text{자기 자신으로 복귀}]=n$이고, 인접한 $d$개의 이웃이 각각 $\frac1d h$만큼 기여해 $E[\text{복귀}]=1+h$가 되기 때문이다.

# 한 줄 요약
> Markov chain은 전이행렬 $P$ 하나로 완전히 결정되고, 장기 행동은 정상분포 $\pi=\pi P$로 요약된다. 흡수 시간·확률 문제는 거의 항상 first-step analysis로 재귀식을 세운 뒤 푸는 것으로 귀결된다.

# 범주-연속형 데이터를 활용한 하이브리드 실험최적설계 AI 모델 개발

## 1. 과제 개요 및 목표

### 1-1. 과제 개요
본 과제는 기존 베이지안 최적화(Bayesian Optimization, BO)가 연속형 변수 중심으로 설계되어, 범주형 변수·이진 결과값·배합비 제약 등 실제 화학/소재 도메인의 복합적 조건을 충분히 반영하지 못하는 한계를 해결하기 위해 수행되었습니다. 현업 데이터의 특성과 실험 운영 제약을 그대로 수용할 수 있는 하이브리드 최적화 알고리즘을 설계하고, 이를 현장 서버에 즉시 배포 가능한 파이프라인으로 구현·패키징하는 것을 목표로 합니다.

### 1-2. 최종 목표
- **Hybrid Optimization**: 연속형 목적함수는 가우시안 프로세스(GP), 이진 목적함수는 AutoML 기반 분류 모델로 처리하는 Two-Track 최적화 엔진 구축.
- **Constraint Handling**: 배합비(Ratio)/총량(Sum) 같은 수치 제약과 논리적 목표(OR)를 처리하는 고도화된 샘플링·확률 계산 기술 확보.
- **Field Deployment**: Python 3.12 기반 모듈형 파이프라인을 Docker 이미지로 패키징하여 현업 환경에 즉시 이관 가능하도록 제공.

## 3. 코오롱측 요구사항에 따른 중간 방향 전환 (Pivot Points)

현업(코오롱) 요구와 실험 운영 현실을 반영하여, 초기 설계안을 다음과 같이 피벗하였습니다.

| 구분 | ① 당초 계획 / 초기 접근 | ② 코오롱측 요구·이슈 | ③ 최종 변경·해결 (Solution) |
| :--- | :--- | :--- | :--- |
| 샘플링 | Rejection Sampling(조건 미충족 샘플 폐기, while-loop) | 배합비·총량 결합 시 연산 지연 및 병목 심각 → 속도·균일성 개선 필요 | DRS 샘플러 도입: 제약공간 내 균일(Uniform) 샘플 즉시 생성, 병목 제거 |
| 목적함수 모델링 | 단일 GP 모델(모든 타깃을 연속형 가정, Pass=1/Fail=0) | Pass/Fail 이진 데이터 비중 큼, 0/1 치환은 예측력 저하 | AutoML 분류 모델 도입: 이진 목표의 성공확률 추정, Two-Track 체계 확립 |
| 목표 설정 논리 | AND 조건(모든 목표 동시 달성) | 물성 A 또는 B 중 하나 달성 시에도 유효(OR 로직 필요) | Or-Group 구현: 독립사건 가정 하 합집합(최소 1개 달성) 확률 계산·반영 |
| 변수 처리 | 연속형 배합비 추천(소수점 단위) | 현장 계량 단위 제약(예: 5% 단위 등)으로 실사용 곤란 | Mixed Space: 배합비에 이산(Discrete) 속성 부여, 현장 호환 레시피 추천 |

요구사항 기반 변경 요약
- 속도와 균일성: 루프형 랜덤 샘플링 → DRS 기반 균일 샘플링으로 전면 교체.
- 데이터 정합성: 연속형 가정 일변도 → 이진 목표 확률화를 통해 실제 평가체계 반영.
- 목표 유연성: AND 고정 → Or-Group 확률 모델로 유연한 의사결정 지원.
- 현장 적용성: 연속값 권고 → 이산 스텝 단위 권고로 실계량 가능성 확보.

## 4. 최종 결과물 및 기존 대비 달라진 것

### 4-1. 최종 결과물
- **지능형 실험최적화 파이프라인(Source Code)**
  - 모듈: Data Process, ML Block, BO Block, Probability Calculator
  - 기능: Mixed Space 최적화, Or-Group 확률 계산, 제약 기반 후보 생성
- **배포용 Docker Image**
  - Python 3.12 기반, 의존성 포함 패키징, 서버 배포 절차 가이드 포함
- **기술 문서 및 매뉴얼**
  - 알고리즘 명세서, 입출력 포맷(Excel/JSON) 가이드, 운영/재현성 지침(로깅·Seed)

### 4-2. 기존 기술 대비 혁신성 (Before vs After)

| 비교 항목 | 기존 베이지안 최적화(Standard BO) | 본 과제 개발 모델(Advanced MOBO) |
| :--- | :--- | :--- |
| 제약조건 처리 | 경계(Bounds) 중심 단순 제약 | 비용(Cost), 배합비(Ratio), 총량(Sum), 그룹(Or-Group)까지 확장 |
| 샘플링 속도·품질 | 제약 복잡도 증가 시 지연·편향 발생 | DRS로 제약 복잡도와 무관하게 고속·균일 샘플 생성 |
| 데이터 수용성 | 연속형 수치 위주 | 이진(Binary)·범주(Categorical)·이산(Discrete) 통합 처리 |
| 목표 유연성 | 동시 달성(AND) 위주 | Or-Group 기반 “최소 1개 달성 확률” 최적화 |
| 현장 적용성 | 소수점 단위 추천값 → 재해석 필요 | 계량 단위 제약 반영(이산 스텝) → 즉시 실험 적용 가능 |

부가 개선점
- 엣지 케이스 대응: 단일 목적함수(qEI), 커널 안정화(ScaleKernel→RBFKernel)로 이상치 std 개선.
- I/O 호환성: Excel/JSON 양방향 표준 정립, 로깅/리포트 일관화.

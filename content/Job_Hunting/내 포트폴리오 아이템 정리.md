# 1. 핵심 프로젝트/연구 경험

## ① Adele Ring 기반 수치 임베딩 연구 (AOE / PFE) — 대표 연구, 1저자
- **핵심 스토리**: LLM이 숫자를 BPE 토크나이저로 쪼개 인식하면서(`3.14` → `3`, `.`, `14`) 대수적 의미가 훼손되고, 이것이 "수치적 환각"으로 이어진다는 문제의식에서 출발. 대수정수론의 **Adele Ring**(유리수를 실수체계+p진수 체계로 동시에 표현하는 환 구조)을 임베딩으로 사용해, **학습 없이(training-free) 결정론적으로** 숫자의 크기·패턴을 보존하는 임베딩 공간(AOE, Adelic Operation-preserved Embedding)을 설계.
  - **AOE의 실제 실험 범위(2026.09, NeurIPS 논문 원문으로 재확인 — 반드시 이 내용으로만 서술)**: nanoGPT/Llama 같은 사전학습 LLM이 아니라, **처음부터 학습시키는 소형 6-layer Transformer 인코더**(dmodel=128, 8 heads, dropout 0.1, [CLS] 토큰+선형 분류기)에 실험. 학습 파라미터가 있는 표준 `nn.Embedding` 룩업을 AOE(실수값+p진수 전개를 이어붙인 training-free 텐서)로 **통째로 교체**하고, 시퀀스 위치·소수 인덱스·자릿수 인덱스를 함께 인코딩하는 2D positional encoding을 추가한 구조. 학습 목적함수는 표준 Cross-Entropy Loss(커스텀 손실 아님). Algebraic Combinatorics Dataset(ACD)의 6개 분류 태스크(lattice paths, weaving patterns, quiver mutation classes, Grassmannian cluster algebras, Schubert polynomial 구조상수, mHeight)로 검증.
  - **AOE 정량 성과**: 논문 Table 1의 6개 태스크·13개 세팅(task×n) 평균 정확도 **66%→92%**(baseline 평균 66.9%→AOE 평균 91.1%, 직접 재계산해 확인), Weaving Patterns(n=6,7)에서 **사상 최초 100% 정확도** 달성. Baseline은 학습 파라미터가 있는 `nn.Embedding`인 반면 AOE는 training-free라 파라미터가 더 적은데도 전 태스크에서 앞섰다는 것이 "파라미터를 늘리지 않고도 구조 설계만으로 성능을 끌어올렸다"는 주장의 근거.
  - **AOE의 한계(논문에 명시, 먼저 꺼낼 필요는 없지만 질문 오면 인정)**: 유리수(ℚ) 범위로 한정(무리수·복소수·초월수는 향후 과제), 소수 개수·자릿수 정밀도는 휴리스틱하게 고정, training-free이지만 사전계산+2D positional encoding 때문에 학습 자체는 표준 임베딩 대비 오히려 4~5배 느림.
  - 확장판(PFE, Prime Fourier Embeddings): Pontryagin 쌍대성/adelic 조화해석에 기반해 정수를 소수-인덱스 (cos,sin) 쌍으로 인코딩, 각 소수 채널이 해당 p진 구조를 복소평면 단위원(S¹) 위 회전으로 담당하도록 설계. 이론적으로는 PFE에 대해 equivariant한 모든 선형사상이 소수별로 독립된 block-diagonal 구조를 가져야 함을 Schur's Lemma로 증명(Block-Diagonal Decomposition Theorem)한 것이 핵심 기여.
  - **PFE의 실험 범위(구분 주의)**: PFE 논문의 실험은 AOE와 마찬가지로 실제 LLM/Transformer가 아니라, 처음부터 학습시키는 소형 전용 분류기(소수별 2-layer 인코더+classifier)로 `(a+b) mod p`, `(a+b) mod N` 같은 합성 modular arithmetic 태스크를 풀게 한 뒤, 소수 채널을 하나씩 ablate하며 CRT가 예측하는 채널 선택성이 실제로 나타나는지 검증한 것(task-relevant 채널 ablate 시 정확도 0.60~0.92 급감, task-irrelevant 채널은 통계적 노이즈 수준).
  - **현재 진행중인 후속 연구(2026.04~, 고려대 산협 연구원, 미게재)와의 경계 — AOE/PFE와 절대 섞지 말 것**: nanoGPT/Llama 코드베이스를 직접 수정해 실제 사전학습 LLM 아키텍처에 Adele 임베딩 모듈을 plug-and-play로 삽입하는 작업, 수치 안정성을 위한 Custom Loss, Muon 옵티마이저 활용은 **AOE(NeurIPS)도 PFE(ICML)도 아니고 전부 이 현재 진행중 단계의 작업**입니다. "LLM에 통합해 학습 효율을 높였다"거나 "nanoGPT/Llama 임베딩 레이어를 직접 수정해 92%를 달성했다"는 식으로 AOE 논문 성과에 갖다 붙이지 말 것 — 자세한 내용은 [[#고려대학교 산학협력단 지속가능자원-환경연구센터 연구원 (2026.04.01~ 현재 재직중) — 최신 경력, CV형 지원서 "현재 회사"란에 등재|현재 진행 중인 후속 연구]] 참고.
- **성과**: NeurIPS 2025 Workshop MATH-AI 게재(1저자, "Numbers Already Carry Their Own Embeddings"), ICML 2026 Workshop AI4MATH 게재(공동 1저자, 황현상과 공동 — 2026.09 현대자동차 지원서 작성 중 본인이 직접 확인해 확정. 이전 기록의 "2저자" 표기는 오기였음).
- **증명하는 역량**: 수리적 모델링, 근본 원인 파악 후 아키텍처 단위 설계, 독자적 연구 수행력, 학습 파라미터 없이 구조적 개선을 이끌어내는 효율성.
- **어디서 썼나**: 거의 전 회사 공통 소재(SAIT, Mistral, SKT, 기아, 롯데이노베이트, 삼성전자, 포스코DX, 퓨리오사, 현대글로비스/로템/모비스/자동차). 자기소개 스피치의 핵심 키포인트로도 사용("수학적 엄밀성을 바탕으로 환각 없는 신뢰할 수 있는 AI를 만드는 연구자").
- **변형 포인트**:
  - *SAIT(전화면접)*: 가장 깊은 수학적 디테일(Adele Ring 정의, p진수 전개, PFE의 조화해석학·Fourier 기반 인코딩) 포함. "Mellin 변환"은 AOE·PFE 어느 논문에도 등장하지 않으므로 쓰지 말 것.
  - *Mistral*: pre-training/post-training 경험 질문에 대해 "raw corpus 사전학습은 아니지만 모델이 정보를 받아들이는 표현 자체를 재설계하는, 한 단계 더 근본적인 작업"이라는 프레이밍으로 방어.
  - *제조/자동차 계열(기아·글로비스·로템·모비스·현대차)*: "수학적 엄밀함으로 데이터 왜곡/연산 오류를 막아 신뢰성 확보" 식으로 산업 안전/신뢰성 프레임에 연결.

## ② PFVL (Process-First, Verify-Later) — Lean4 연동 Agentic 자동 수정 시스템 및 Preprint 논문
- **정확한 기간**: 2025.05.22~2025.06.21, "수리인공지능세미나" 전공수업 프로젝트로 시작(SKT/LG에너지솔루션 CV형 지원서의 "전공수업 프로젝트" 항목에 이 기간·출처로 정식 등재), 이후 Preprint 논문 완성.
- **핵심 스토리**: 자연어 수학 문제를 Lean4(정리증명 언어, v4.20.0) 코드로 변환하고, 외부 Lean4 컴파일러가 검증한 에러 로그(`returncode`, `stderr`)를 LLM에 피드백으로 재주입해 **최대 3회까지 스스로 코드를 수정**하는 Training-free 멀티턴 Agentic 루프인 **PFVL (Process-First, Verify-Later)** 프롬프팅 프레임워크를 설계.
  - **3단계 파이프라인**: 
    1. Phase 1(Initial Solution & Formalization): CoT 자연어 풀이 생성 및 단계별 분해 + 병렬 Lean4 정리 명제(Formal Statement) 생성.
    2. Phase 2(Step-by-Step Code Generation): 분해된 CoT 단계를 바탕으로 점진적 Lean4 코드 생성 및 중간 코드 결합(스노우볼링 방지).
    3. Phase 3(Feedback-Driven Code Refinement): Lean4 컴파일러 피드백 기반 최대 3회 자가 수정 루프.
  - GPT-4o, Claude Opus 4, Gemini 2.0 Flash, Perplexity Sonar, OpenAI o4-mini 등 다중 상용 SOTA LLM 대상 실증 분석 수행. LangChain/LangGraph 같은 고차원 프레임워크 없이 **순수 Python으로 직접 구현**(컴파일러와의 세밀한 동기화 목적).
  - **정량 성과 (Preprint 논문 기준)**:
    - **ProofNet**(학부 순수수학 371문항): Claude Opus 4 기준 제로샷 베이스라인 4.58%(17개) 대비 **8.63%(32개 valid)**로 **정확도 약 2배(twofold) 향상**.
    - **MiniF2F**(경시대회 488문항): 전체 정확도 19.26%(94개 valid), 특히 **대수(Algebra) 카테고리에서 62개 문제를 해결**하여 베이스라인(56개, 52개)을 크게 능가.
    - 유효 Lean4 코드 생성 시의 추론 시간이 오류 코드 대비 약 57% 짧다는 점을 정량 규명(시간 기반 탐색 전략 및 신뢰도 측정 가능성 제시).
  - **논문**: "Code to Reason in Math is Still Hard for Well-known LLMs" (Preprint).
- **증명하는 역량**: Agentic AI 시스템 설계, 신뢰성/가드레일 설계, 외부 검증기(Formal Verifier) 연동 파이프라인, 프레임워크 독립적 로우레벨 구현력, 벤치마크 기반 정량 분석 능력.
- **공개 레포화(2026.09.29 확인)**: 공개 레포로 전환 가능(아직 공개 전). NAIS 연구직-10 기타실적(GitHub 캡처)에 제출 예정. 전공수업 프로젝트이므로 공동 작업자 유무와 기여 범위를 README에 명시할 것.
- **어디서 썼나**: 2026상반기 자소서 다수 — SKT(에이닷 CV), 삼성전자(에이전틱 AI 다크팩토리), 포스코DX(Agentic Workflow 직무 핵심 소재), 현대글로비스("발생가능한 문제를 예측하고 대비한 경험" 문항에 정면 매칭), 퓨리오사(Robust & Reliable Design 관심분야), 한화에어로스페이스(무인 agent 제어 비전과 연결), NAIS(자율형과학시스템 지원동기·전문역량).
- **변형 포인트**: 포스코DX·한화에어로 등 "직무 자체가 Agentic Workflow"인 곳에서는 이 프로젝트가 지원동기 문항의 메인 소재로 격상됨. 글로비스는 "문제 예측·대비" 행동 문항에 정확히 대응. NAIS에서는 "과학 추론 모델의 외부 검증기 연동 및 보상 신호 설계" 역량으로 매핑.

## ③ 2025 SCPC(삼성 AI Challenge) — 온디바이스 VLM 개발 (본선 진출, 상위 9%/23위)
- **핵심 스토리**: 스마트폰 급 제한 자원(3B 파라미터 미만, RTX 3090 단일 GPU, 2024년 이전 공개 모델만 허용)에서 이미지 기반 5지선다 문제를 푸는 온디바이스 VLM 개발.
  - **Two-Stage 파이프라인** 직접 설계: KOSMOS-2(이미지 캡셔닝, 최대한 상세하게 생성하도록 훈련) → Flan-T5(캡션 기반 5지선다 추론).
  - 최적화: QLoRA(파라미터 효율 학습), Flash Attention v2(HBM-SRAM I/O 병목 해결), torch.compile(커널 퓨전으로 레이어 간 데이터 이동 최소화), 커리큘럼 러닝(난이도 순 학습으로 훈련 안정성 확보).
  - 정량 성과: 총 파라미터 2.74B(1.95B+0.78B), **메모리 사용량 약 75% 절감, 추론 속도 약 1.2배 향상**, 리더보드 0.75점으로 **전체 23위(상위 9%) 본선 진출**.
- **증명하는 역량**: 하드웨어 인식 최적화(hardware-aware optimization), 제약 조건 하의 엔지니어링, 멀티모달 파이프라인 설계.
- **어디서 썼나**: 사실상 전 회사 공통(2024 SK매직·네이버는 시기상 이전이라 미포함, 2026상반기 전체에 등장 — 기아, 롯데이노베이트, 삼성전자, 포스코DX, 퓨리오사, 현대글로비스/로템/모비스/자동차, Mistral, 카카오 스크리닝 면접에서 가장 깊게 질문받음).
- **변형 포인트**: 카카오 ML 스크리닝 면접에서 LoRA rank/alpha, quantization 적용 범위(전체 모델 vs 어댑터만) 등 아주 디테일한 꼬리질문을 받음 — 관련 답변 근거 필요. 기아/현대차 계열에서는 "제약된 자원에서 안정적으로 구동하는 최적화 모델 설계 역량"의 증거로 프레이밍.

  - 제목: "대형 언어 모델 질의응답 생성 텍스트 환각 분류 및 텍스트 평가 척도의 한계 탐구" / "Exploring Hallucination Types in Question-Answering Generation and Limitation of Text Evaluation Metrics" (KCC 2024, 포스터 발표, 1저자).
- **증명하는 역량**: 정량적 실험 설계력, 문제를 구조화/유형화하는 능력, 평가지표 자체에 대한 비판적 사고.

## ⑧ 코오롱 산학협력 & TRMC-BO — 다중 제약 신소재 실험최적설계 AI (MOBO, 2025.01–08 & NeurIPS 2026 Workshop Preprint)
- **핵심 스토리**: 코오롱과의 산학협력 과제로, 전통적 소재 실험이 겪는 "높은 시행 비용·전문가 직관 의존"의 한계를 풀기 위해 **Multi-Objective Bayesian Optimization(MOBO)** 기반의 신소재 실험 최적설계 알고리즘을 개발하고, 이를 발전시켜 학술 연구 논문(**TRMC-BO**, NeurIPS 2026 AI4Mat 워크숍)으로 고도화함.
  - **기초 산학과제 성과 (2025.01–08, 3인 공동연구: Bosung Jung, Suhyun Bae, Hanyoung Kim, 지도교수 이동헌)**:
    - **Two-Track 모델링**: 목적함수 성격에 따라 연속형 물성은 Gaussian Process(GP), 이진형(Pass/Fail)은 AutoML(CatBoost, Extra Trees 등 앙상블 분류모델)로 분리 처리. **이 중 AutoML 모듈은 본인이 단독 설계·구현**.
    - **복합 제약 처리**: 배합비/그룹별 합 등식 제약, 비용 부등식 제약, Or-Group 확률 계산(독립사건 가정 하 합집합 확률) 구현.
    - **Mixed Space & 계량 단위 최적화**: 연속형·이산형·범주형 변수를 함께 다루는 Mixed Variable BO 구현, 현장 계량 단위(예: 5% 스텝) 제약 반영.
    - **DRS(Dirichlet-Rescale) 샘플링 알고리즘 도입**: 기존 Rejection Sampling의 심각한 속도 병목을 제약공간 내 균일(Uniform)한 샘플을 즉시 생성하는 DRS 알고리즘으로 전면 대체해 병목 제거.
    - **현업 피드백 기반 4단계 피벗 및 배포**: Python 3.12 + Docker 기반 모듈형 파이프라인 패키징, Excel/JSON 입출력 지원, 특허 출원 및 코오롱인더스트리 전사 도입 완료.
  - **후속 논문 연구: TRMC-BO (Target-Range, Multiple-Constraint BO, NeurIPS 2026 AI4Mat Workshop Preprint, 공동 1저자)**:
    - **문제의식 전환 (Portfolio Recovery)**: 신소재 배합은 단일 최적해를 찾는 "One-winner" 문제가 아니라 공정성·비용·스케일업 유연성을 위해 목표 물성 구간($L \le f(x) \le U$)을 만족하는 여러 유효 배합을 회수하는 "Portfolio Recovery" 문제임. 기존 평가 지표인 적중률(Hit rate)이 한 점 주변만 반복 샘플링하는 제안 집중(Proposal Concentration)을 숨긴다는 점을 실증 규명.
    - **TRMC-BO 3대 핵심 기둥(Three Pillars)**:
      1. *Pillar 1 (Known Input Feasibility)*: 조성 심플렉스(DRS 기반), 원료 수(cardinality), 비용 예산 제약을 초기 설계 및 획득함수 최적화기에 직접 강제해 탐색 공간에서 유효하지 않은 배합을 원천 배제.
      2. *Pillar 2 (Range Acquisition via qEHVI)*: 물성별 구간 만족 확률을 단일 스칼라 곱으로 뭉개지 않고 목적함수 벡터로 유지하여 초부피 개선(qEHVI)으로 획득, 목적 공간의 다양성 보존.
      3. *Pillar 3 (Optimizer-level Dual Window Enforcement)*: 획득함수 최적화기에 사후 평균 양방향 부등식 제약($\mu_k - L_k \ge 0, U_k - \mu_k \ge 0$)과 시작점 필터를 직접 적용. 윈도우 내부에서는 제약 기울기가 소멸(Slack-gradient)하여 중심으로의 인위적 쏠림 없이 윈도우 내 다양한 배합을 광범위하게 탐색.
    - **정량 성과**: MatFormBench(5개 과제) 및 Olympus(폴리머/박막 혼합물 등) 총 3,570회 벤치마크 실험 수행. 가장 강력한 외부 베이스라인 대비 유효 분산 배합(Distinct Valid Designs) **1.3~2.2배** 더 많이 회수, Tolerance Ball 계열 대비 **3.7~7.2배** 우위. 적중 대비 고유 유효 배합 변환율 34~93% 달성 (베이스라인은 2~33%에 불과).
    - **이론/분석 기여**: Hit rate와 Distinct Design 지표 순위가 정반대로 뒤집히는 'Metric Reversal' 현상 실증, 단일 출력 획득함수의 힌지 포화(Hinge Saturation) 메커니즘을 수학적·실험적으로 규명.

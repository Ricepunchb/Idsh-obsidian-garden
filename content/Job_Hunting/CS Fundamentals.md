# 1. What is an Algorithm?
**Answer:** An algorithm is a step-by-step set of instructions designed to perform a specific task or solve a problem. 
**Explanation:** In computer science, algorithms are the foundation of programming and problem-solving. They define the logical sequence of actions that a computer program must follow to achieve a goal. Algorithms can be simple (finding the largest number in a list) or complex (sorting millions of records efficiently). 
**Why Important:**
- Algorithms ensure efficiency and correctness in programs.
- They help optimize performance in terms of speed and memory.
- Algorithms form the backbone of technical interviews, testing problem-solving ability.
**Example:** A simple algorithm to find the largest number in an array:
Start with the first number as the largest.
Compare each number in the array.
Update the largest if a bigger number is found.
Return the largest at the end.

# 3. What is a Database and Database Management System (DBMS)?
**Answer:** A database is an organized collection of data, and a Database Management System (DBMS) is the software used to create, manage, and manipulate that data efficiently. 
**Explanation:** A DBMS (like MySQL, Oracle, MongoDB) allows data storage in structured or unstructured forms, querying using SQL, and enforces security. Types include Relational DBMS (RDBMS) using tables, and NoSQL DBMS for large-scale data. 
**Why Important:**
- Essential for almost all modern applications.
- Ensures secure, consistent, and efficient data handling and multi-user access.
- Interviewers expect freshers to know database basics as most applications depend on them.
**Example:** An e-commerce website stores user details, product information, and transactions in databases like MySQL or MongoDB.

# 4. What is Object-Oriented Programming (OOP)?
**Answer:** Object-Oriented Programming is a programming paradigm based on the concept of "objects," which combine data (attributes) and methods (functions). 
**Explanation:** The core principles (OOPS Pillars) include Encapsulation (wrapping data and methods), Abstraction (hiding implementation details), Inheritance (reusing code by deriving new classes), and Polymorphism (methods behaving differently). 
**Why Important:**
- Makes code reusable and modular.
- Helps in building complex systems in a structured manner.
- Reduces code duplication and is widely tested in coding interviews.
**Example:** In Python or Java, a `Car` class can have properties (color, model) and methods (drive, stop). Multiple car objects (e.g., Tesla, Ford) can be created using the same class.

# 5. What is an Operating System (OS)?
**Answer:** An Operating System is system software that manages computer hardware and software resources and provides services for applications and users. 
**Explanation:** The OS acts as a bridge between the user and the hardware. It handles process management, memory management, file system management, device management, and security. Types include Batch, Time-sharing, Distributed, and Real-time OS. 
**Why Important:**
- Provides crucial resource management (CPU, memory, storage) and multitasking.
- Ensures system security and prevents applications from crashing.
- Fundamental knowledge expected from freshers for troubleshooting and system design.
**Example:** Windows, Linux, macOS, Android. When you open multiple apps, the OS handles task scheduling so they run concurrently without issues.

# 6. What is Computer Networking?

**Explanation:** Networks can be classified as LAN, MAN, WAN, or PAN based on their size and range. Topologies include Bus, Star, Ring, and Mesh. Protocols like TCP/IP, HTTP, and FTP govern the communication.

# 8. What is Compiler and Interpreter?
**Answer:** A Compiler converts the entire code into machine language before execution, while an Interpreter translates code line-by-line during execution.
**Explanation:** Compiled languages (C, C++) run faster but take time to compile. Interpreted languages (Python, JavaScript) are slower but easier to debug. 
**Why Important:**
- Helps freshers understand programming language behavior.
- Useful in choosing the right language for a project.
**Example:**
- C uses a compiler.
- Python uses an interpreter.

# 11. What is the difference between HTTP and HTTPS?
**Answer:** HTTP is a protocol for transferring data over the web, while HTTPS is a secure version of HTTP that uses encryption (SSL/TLS).
**Explanation:** HTTP allows data transfer between a web browser and server but lacks encryption, making it vulnerable. HTTPS encrypts communication to secure sensitive information like login credentials or payment details. 
**Why Important:**
- HTTPS builds trust for websites, especially in e-commerce and banking.
- Search engines like Google prefer HTTPS websites in SEO ranking.
- Protects users from attacks like man-in-the-middle (MITM).
**Example:**
- http://example.com (not secure).
- https://example.com (secure, with a padlock icon in the browser).

# 13. What are Primary, Foreign, and Unique Keys in a Database?
**Answer:** A Primary Key uniquely identifies a record, a Foreign Key establishes a relationship between two tables, and a Unique Key ensures all values in a column are distinct. 
**Explanation:** A Primary Key permits no duplicates and cannot be NULL. A Foreign Key references a primary key in another table to enforce referential integrity. A Unique Key allows multiple unique values and permits one NULL. 
**Why Important:**
- Maintains relational data integrity and logical structuring.
- Common interview question in SQL/database rounds.
**Example:** Table `Students` (StudentID PRIMARY KEY, Name). 
Table `Marks` (MarkID, StudentID FOREIGN KEY, Score). 
Here, `StudentID` links both tables.

# 14. What is Normalization and Denormalization in Databases?
**Answer:** Normalization organizes a database to reduce redundancy and improve data integrity, while Denormalization intentionally adds redundancy to improve read performance. 
**Explanation:** Normalization divides large tables into smaller ones through forms (1NF, 2NF, 3NF, BCNF) to remove dependencies. Denormalization combines tables to reduce complex, slow joins (often used in data warehouses). 
**Why Important:**
- Normalization prevents anomalies (Insert, Update, Delete) and saves storage.
- Denormalization allows faster queries in real-time or big data applications.
**Example:** Normalization splits `Student` and `Course` details into separate tables. Denormalization directly stores `CustomerName` in the `Orders` table to speed up reporting.

# 17. What is Recursion in Programming?
**Answer:** Recursion is a programming technique where a function calls itself directly or indirectly to solve a problem. 
**Explanation:** Every recursive function typically has a Base Case (which stops the recursion) and a Recursive Case (where the function calls itself with a smaller input). 
**Why Important:**
- Simplifies code for divide-and-conquer algorithms, tree/graph traversal, and factorials.
- Tests a candidate’s problem-solving ability and understanding of stack memory.
**Example:** 

```python
def factorial(n):     
    if n <= 1: return 1     
    return n * factorial(n - 1)
```

# 18. What is the difference between Static and Dynamic Memory Allocation?

**Answer:** Static Memory Allocation occurs at compile time, whereas Dynamic Memory Allocation occurs at runtime.

**Explanation:** Static allocation uses a fixed size (e.g., standard arrays). Dynamic allocation uses pointers and functions like `malloc()` in C to allow flexible sizing.

**Why Important:**

- Efficient memory management is crucial in programming.
    
- Interviewers check understanding of runtime vs compile-time concepts.
    
    **Example:**
    
- Static: `int arr[5];` (size fixed).
    
- Dynamic: `int *arr = malloc(5 * sizeof(int));` (size flexible).
    

# 19. What are Processes, Threads, and Multithreading?

**Answer:** A Process is an independent program in execution, a Thread is a lightweight unit of execution within a process, and Multithreading is the ability to run multiple threads concurrently.

**Explanation:** Processes have separate, isolated memory spaces. Threads share memory within the same process. Multithreading allows tasks like I/O and computation to run in parallel, though it requires synchronization.

**Why Important:**

- Essential for understanding multitasking, parallelism, and CPU efficiency.
    
- A core topic in OS and system design interviews.
    
**Example:** A web browser is a single process. Having multiple tabs open, or rendering UI while downloading a file, are handled by multiple threads.
    

# 20. What is Deadlock in Operating Systems?

**Answer:** A deadlock is a situation in an OS where two or more processes are blocked forever, each waiting indefinitely for resources held by the other.

**Explanation:** Deadlocks occur when four conditions (Coffman’s conditions) hold simultaneously: Mutual exclusion, Hold and wait, No preemption, and Circular wait.

**Why Important:**

- Deadlocks freeze systems and severely affect reliability.
- Interviewers test knowledge of resource management, deadlock prevention, and avoidance (e.g., Banker’s Algorithm).

**Example:** Process A holds the Printer and waits for the Scanner, while Process B holds the Scanner and waits for the Printer. Both wait forever.
    

# 21. What is Virtual Memory and Paging in OS?

**Answer:** Virtual Memory is a management technique that uses part of the hard disk as an extension of RAM. Paging is the scheme used to divide processes into fixed-size pages to efficiently map this memory.

**Explanation:** When physical RAM is full, the OS moves less-used data into a disk "swap space" to prevent crashes. Logical memory is divided into pages, and physical memory into frames, using a Page Table for mapping (eliminating external fragmentation).

**Why Important:**

- Allows large programs to run on limited physical RAM.
    
- Ensures efficient memory utilization.
    
- Heavily tested memory management concept in interviews.
    
**Example:** If a system has 4 GB RAM and runs a 6 GB program, the extra 2 GB is handled by virtual memory. The program is split into small pages loaded into available RAM frames dynamically.

# 23. What is a Linked List?
**Answer:** A Linked List is a linear data structure where elements (nodes) are connected using pointers.
**Explanation:** Each node contains data (value) and a pointer (address of the next node). Types include Singly Linked List (points forward), Doubly Linked List (points forward and backward), and Circular Linked List (last node points to first). 
**Why Important:**
- Useful for dynamic memory allocation (size can grow/shrink dynamically unlike arrays).
- Interviewers ask linked list coding questions to test logic and pointer manipulation.
**Example:** A playlist navigation system uses a doubly linked list for "next" and "previous" songs.

**Why Important:**

# 25. What is a Stack?

**Answer:** A Stack is a linear data structure that follows the LIFO (Last In, First Out) principle.

**Explanation:** Core operations are Push (insert), Pop (remove), and Peek (view top element). It can be implemented using arrays or linked lists.

**Why Important:**

- Used in function calls (call stack), undo operations, and expression evaluation.
    
- Interviewers often ask to implement stack logic.
    
    **Example:** Browser back/forward navigation or reversing a string.
    

Python

```
stack = [] 
stack.append(10)  # Push 
stack.pop()       # Pop  
```

# 26. What is a Queue?

**Answer:** A Queue is a linear data structure that follows the FIFO (First In, First Out) principle.

**Explanation:** Core operations are Enqueue (insert at rear) and Dequeue (remove from front). Types include Simple Queue, Circular Queue, and Priority Queue.

**Why Important:**

- Used in task scheduling, CPU processes, and printer spooling.
    
- Key concept in OS and system design interviews.
    
    **Example:** A ticket booking system where the first customer is served first.
    

Python

```
from collections import deque 
queue = deque([1,2,3]) 
queue.append(4)     # Enqueue
queue.popleft()     # Dequeue  
```

# 27. What is a Hash Table?

**Answer:** A Hash Table is a data structure that stores key-value pairs and allows fast data retrieval using a hashing function.

**Explanation:** A hash function maps keys to an array index. If two keys map to the same index (collision), techniques like chaining or open addressing are used. It provides average O(1) time complexity for insert, delete, and search.

**Why Important:**

- Fundamental for building efficient lookup systems and caching.
    
- Interviewers test hash table logic heavily.
    
    **Example:** A Python `dict` is implemented using hash tables.
    

Python

```
students = {"Amit": 90, "Riya": 85} 
print(students["Amit"])  # Output: 90  
```

# 28. What is Dynamic Programming (DP)?

**Answer:** Dynamic Programming is an optimization technique used to solve problems by breaking them into smaller subproblems and storing their results to avoid recalculation.

**Explanation:** DP relies on overlapping subproblems and optimal substructure. Techniques include Top-down (memoization using recursion + caching) and Bottom-up (tabulation using iterative loops).

**Why Important:**

- Essential for solving complex algorithmic problems efficiently.
    
- Extremely common in competitive programming and technical interviews.
    
    **Example:** Calculating Fibonacci numbers using a memoization dictionary to avoid recomputing the same values.
    

# 29. What is TCP/IP Model?

**Answer:** The TCP/IP (Transmission Control Protocol/Internet Protocol) model is a networking framework that defines communication across networks.

**Explanation:** It consists of four layers: Application (HTTP, FTP), Transport (TCP - reliable, UDP - fast), Internet (IP, routing), and Network Access (Ethernet, Wi-Fi).

**Why Important:**

- The entire Internet runs on TCP/IP.
    
- Interviewers expect basic networking protocol knowledge from freshers.
    
    **Example:** When opening a website, HTTP (Application) requests the page, TCP (Transport) ensures reliable data delivery, and IP (Internet) routes the packets.
    

# 30. What is Big O Notation?

**Answer:** Big O Notation describes the time or space complexity of an algorithm in terms of its input size.

**Explanation:** Common complexities include O(1) (Constant), O(log n) (Logarithmic), O(n) (Linear), O(n log n) (Efficient sorting), and O(n²) (Nested loops).

**Why Important:**

- Helps evaluate and compare algorithm efficiency.
    
- A mandatory interview topic for any coding/engineering role.
    
    **Example:** Searching in an unsorted array takes O(n), Binary Search takes O(log n), and Merge Sort takes O(n log n).

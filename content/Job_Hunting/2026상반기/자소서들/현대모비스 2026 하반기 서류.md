# 조직소개
**FTCI - SW/로직 - 알고리즘(AI/제어) - 마북연구소**
우리 조직은 현대모비스의 선행기술 개발을 담당하는 부서 중 하나로,

차량을 포함한 다양한 모빌리티 환경에 적용할 수 있는 모빌리티 AI 및 융복합 데이터 기반의 최신 기술을 개발하고 있습니다.

컴퓨터공학, 전자공학 등 다양한 분야의 전공자들이 모여 미래 모빌리티 적용을 위한 기술적 경계를 지속적으로 확장해 나가고 있습니다.

## 직무
**모빌리티 AI 기술 선행 개발**

- LLM/MLLM 기반 차량용 AI Agent 기능 개발  
    - LLM/Multimodal LLM 기반 탑승자 의도 이해, 대화 흐름 제어, 기능 호출, 응답 생성 기능 개발
    - 차량 내 영상, 음성 인터랙션, 차량 상태 정보 등의 멀티 모달 입력을 활용한 Context-aware Agent 기능 개발  
    
- AI Agent 기반 차량 서비스 및 기능 연동 개발  
    - 내비게이션, 공조, 미디어, 전화, 일정, 차량 설정 등 차량 기능과 연계 되는 Agent 기능 개발  
    - 사용자 요청을 차량 기능 제어 명령으로 변환하기 위한 Tool use, Function calling, API 연동 기능 개발
      
- AI Agent 프로토타입 개발 및 차량 적용성 검증  
    - 차량 환경에서 Agent 응답 품질, 기능 수행 정확도, 실시간성 검증  
    - 차량 환경에 적합한 Agent 운영 방식, 안정성, 예외 처리, 사용자 경험 개선 방안 도출

- AI Agent, 대화형 AI, LLM, MLLM 기술에 대한 이해 보유자

- 차량, 로봇, 모바일, 임베디드 환경 중 하나 이상에서 AI 적용 경험 보유자

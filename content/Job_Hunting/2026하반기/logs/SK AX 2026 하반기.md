# JD
## 조직소개
**AI Tech Innovation 팀**
- 저희팀은 sLLM 파인튜닝과 LLMOps, AI Agent, 온톨로지 기반 데이터 체계 등 AI 코어 기술을 연구해 회사에 내재화하는 조직입니다.
- 확보한 기술은 전사 AI 플랫폼의 서비스로 제공되고, 다양한 산업의 고객사 과제와 전사 AI 개발에 사용되고 있습니다.
- LLM Agent 기반 응용 시스템과 Agent 평가 체계 만들어 가고 있습니다.

## 업무 환경 및 문화

- 앞으로 니즈가 생길 분야의 기술을 스스로 찾아 검증을 시작합니다.
- 개발만이 아니라 검증, 분석, 문서화까지 AI를 전문적으로 쓰고, 그 활용 방식을 표준으로 사용합니다.
- 새 모델과 도구는 소개 자료가 아니라 직접 써 본 결과를 스스로 판단하고 제안할 수 있는 자율적인 환경을 제공합니다.
- 리서치를 위한 리서치는 하지 않습니다. 검증한 기술을 사업과 연결해 실질적인 가치를 만드는 데 집중하고, 되지 않는 것은 근거를 남깁니다.
## 담당 업무
- LLM Agent 기반 응용 시스템을 설계하고 개발합니다. Agent Harness, Reasoning 활용, Agent Skills 같은 동작 구조를 직접 다룹니다
- Agent의 품질과 보안을 평가하는 체계를 만들고 실행합니다.
- Agent 동작을 추적할 수 있는 Logging, Tracing, Evaluation 환경을 실제 환경에 구축합니다.
- Agent 분야의 핵심 기술과 새로운 기술을 검증하고 적용 기준을 만들어 갑니다.
- 고객사 과제의 요건 구체화부터 구축과 시연까지 직접 참여합니다.
- ※ 근무지 : 경기도 분당
## 필요 역량 및 경험

- API 기반 비동기 시스템을 설계하고 운영한 경험이 있으신 분
- Tool calling과 RAG 구현을 포함하여 LLM을 사용한 시스템을 직접 만들어 본 경험이 있으신분
- Agent 품질을 평가하거나 디버깅한 경험이 있으신 분
- 새 기술을 검증하고 그 판단 근거를 글로 정리하고 설명할 수 있는 분
- Git 기반 협업과 컨테이너 환경에 대한 이해가 있으신분
## 우대사항

- Multi-Agent 구조를 설계하고 운영해 본 경험이 있으신 분.
- Tool 권한 제어, Prompt Injection 대응, Agent Guardrail 등 LLM과 Agent 보안 관련 경험이 있으신 분.
- LLM 평가 체계나 벤치마크를 직접 설계하고 측정해 보신 분.
- 코딩 에이전트를 실제 개발 업무에 적용해 본 경험이 있으신 분.
- 외국어 능력으로 글로벌 커뮤니케이션에 능하신 분
## 성향 및 캐릭터

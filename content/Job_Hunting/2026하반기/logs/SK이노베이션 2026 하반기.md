# JD
## 조직소개
AX단은 전사 AI Transformation 전략에 따라 AI를 활용한 업무 혁신과 실질적인 성과 창출을 추진합니다. 과제별로 필요한 데이터와 기술을 정하고, 해결방안을 설계해 실제 업무에 적용합니다. AI Agent와 예측·탐지·최적화모델을 개발해 현장의 문제 해결도 돕습니다.

개별 과제가 전사로 확산될 수 있도록 AI Agent 개발 프레임워크와 표준 Skill, 평가·운영 기준도 마련합니다. 경영진과 본사 주요 조직, 현업과 협력해 AI가 업무 성과와 지속적인 일하는 방식의 변화로 이어지도록 지원합니다. 

이를 위해 데이터 수집·가공부터 AI 활용, 업무 시스템 연계, 클라우드 실행 환경까지 필요한 데이터·AI 플랫폼과 IT 인프라를 개발·운영합니다. 여러 구성원이 안전하고 편리하게 활용할 수 있는 공통 기능과 운영 체계를 마련하고, 안정성·보안·품질·비용 효율성을 높여 데이터와 AI가 지속 가능한 서비스로 자리 잡도록 돕습니다.

## 수행업무
### AI Agent 설계, 개발
- 현업 업무 프로세스를 이해하고 AI agent로 지원할 수 있는 업무 영역 도출
- 사내 문서, 데이터를 활용한 검색, 요약, 질의응답, 업무 자동화 기능 개발
- AI agent가 업무 시스템과 연계되어 동작할 수 있도록 필요한 기능 구현
- Agent의 응답 품질, 근거성, 안정성, 사용성을 점검하고 개선
### 데이터 분석 및 모델 개발
- 공정, R&D, 마케팅, 전략 및 재무, 에너지 전환 등 다양한 도메인의 데이터 분석
- Python 기반 데이터 전처리, 탐색적 분석, feature engineering 수행
- 예측, 탐지, 최적화 문제 해결을 위한 Machine learning 및 Deep learning 모델 개발
- 모델 성능을 검증하고 분석 결과를 현업이 이해할 수 있는 형태로 정리
### AI 과제 구현 및 업무 적용 지원
- 과제별 문제 정의, 필요 데이터, 활용 기술, 구현 방안 구체화 지원
- Prototype을 개발하고 실제 업무 적용 가능성 검증
- AX전략 및 AX 실행 조직, Data 플랫폼팀, AI Frontier, 협업 조직과 협업하여 과제 수행
- 적용 결과를 바탕으로 기능, 모델, 업무 프로세스 개선 사항 도출
### 전사 공통 AI 기술 자산 개발 지원
- AI agent 개발 Framework, 개발 Skeleton, 표준 Skill 등 공통 기술 자산 개발 지원
- 반복 활용 가능한 Agent 개발 패턴, Prompt 및 Tool 설계 방식, 평가 기준 정리
- AI 과제 수행 과정에서 확보한 기술과 노하우를 문서화하여 전사 확산 지원
### 개발 품질 관리 및 협업
- Git 기반 협업, 코드 리뷰, 테스트, 기술 문서 작성 수행
- Databricks, Azure 등 데이터 및 클라우드 환경을 활용한 분석 및 개발
- 다양한 전공과 직무의 구성원들과 협업하여 실제 업무에 쓰이는 결과물 완성
## 필수요건
- Python 등 하나 이상의 프로그래밍 언어로 데이터를 처리 및 분석하거나 기본 기능을 구현하고, 작성한 코드의 동작을 설명할 수 있는 역량
- AI 또는 데이터 기반 기능의 구현 결과를 확인하고 오류 원인을 찾아 개선하는 기초 문제 해결 역량
- LLM 또는 AI 기반 프로젝트 수행 경험
- 새로운 도메인과 기술을 빠르게 학습하여 업무에 적용하려는 태도
- 유관 부서를 넘어 다양한 조직과 열린 자세로 소통 및 협업하며 공동의 목표 달성에 기여할 수 있는 자
- 비즈니스 문제를 데이터 및 기술 과제로 정의하고, 분석 결과를 비즈니스 언어로 전달해 실행 가능한 해결책으로 연결하는 역량
- ※ 교육·실습·개인 또는 팀 프로젝트 경험으로 역량을 확인하며, ML, DL, AI Agent, MLOps 등 데이터·AI전 영역의 숙련도를 요구하지 않습니다.
## 우대요건
- 컴퓨터공학, 산업공학, **수학**, 통계학, 화학공학, 기계공학 등 데이터 분석, 모델링, 수리적 문제 해결과 관련된 전공 또는 이에 준하는 학습 경험
- AI/LLM 관련 공모전, 해커톤 등 참여 및 수상 경력
- Python 기반 데이터 전처리, 탐색적 분석, 모델링 또는 Agent Framework 개발 경험 (LangGraph, AutoGen 등)
- AI Native 개발 환경 활용 경험: Coding Agent (Codex, Claude Code, Antigravity 등) 및 Loop engineering을 활용한 생산성 극대화
- Machine Learning, Deep Learning, Statistics 등을 활용한 예측, 분류, 탐지 모델 개발 경험
- SQL, 데이터베이스, 데이터 파이프라인 등 Data Engineering에 대한 기초 이해
- Databricks, Microsoft Azure 등 데이터, 클라우드 플랫폼 활용 경험
- Git 기반 협업, 테스트 코드 작성 또는 반복 작업 자동화 경험
- ※ 모든 우대 요건을 갖출 필요는 없으며, 한 분야에서의 본인 기여와 학습 및 개선 과정도 중요하게 참고합니다.특정 제품·플랫폼 경험은 필수 요건으로 제한하지 않습니다.
## 기타
- 산업공학, 기계공학, 화학공학, 컴퓨터 과학 등 다양한 전공 배경을 가진 AI 전공 구성원이 함께 일하고 있습니다.
- 입사 초기에는 박사급 동료와 pair로 과제를 수행하며 업무 도메인, 데이터 구조, AI agent 개발 방식 등 실무 역량을 단계적으로 쌓게 됩니다. 이후 난이도가 상대적으로 낮은 과제부터 직접 리드하며, SK이노베이션의 핵심 비즈니스 문제를 AI로 해결하는 Data Scientist로 성장하게 됩니다.
- 성과 우수자의 경우 학위과정 지원 제도 등을 통해 장기적인 전문성 성장을 지원합니다.

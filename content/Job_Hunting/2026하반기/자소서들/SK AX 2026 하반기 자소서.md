# 자기소개서

### 지원 동기와 본 직무를 잘 수행할 수 있다고 생각하는 이유에 대하여 본인의 보유 강점과 경험을 기반으로 기술해주세요. (자유분량)

SK AX에 지원한 이유는 직접 검증한 Agent 기술을 여러 산업의 고객사 현장까지 끝까지 가져가는 곳이기 때문입니다. 일반 상용 AI 서비스는 답변이 그럴듯하면 충분하지만 기업의 실제 업무를 맡는 Agent는 한 번의 잘못된 판단이 곧 고객사의 비용이 됩니다. 그래서 Agent가 무엇을 근거로 움직였고 어디서 틀렸는지 추적하고 평가하는 체계가 모델 성능만큼 중요합니다. AI Tech Innovation팀은 Agent 응용 시스템과 평가 체계를 직접 만들어 전사 AI 플랫폼과 고객사 과제에 적용하고 되지 않는 기술은 근거를 남기는 조직입니다. 저는 SK매직(현 SK인텔릭스) 신제품 TF에서 책상 위에서 맞던 알고리즘이 실제 하드웨어 앞에서 어긋나는 순간을 겪었습니다. 그 뒤로 수학 증명 Agent와 실제 돈이 오가는 투자 Agent를 직접 만들며 AI가 틀리는 지점을 코드로 막는 일에 집중해 왔습니다. 이 경험이 서비스 하나에 머물지 않고 여러 고객사가 믿고 쓰는 Agent의 기준으로 이어질 수 있는 곳이 SK AX라고 판단했습니다.

[AI에게는 제안만 맡기고 지켜야 할 규칙은 코드로 못 박다]
한국투자증권 API와 Gemini를 연결해 주식을 자동으로 사고파는 투자 Agent를 직접 만들었고 지금도 실제 계좌 3개로 운영하고 있습니다. 처음에는 종목 선택과 비중 조정을 AI에게 폭넓게 맡겼습니다. 그러자 AI는 검토 대상에 없던 종목을 지어내거나 포트폴리오를 한 번에 크게 뒤집자고 제안했습니다. 하락장에서는 반등 신호만 보고 계속 사들이다가 손절을 35번 반복했고 6개월 백테스트 결과는 -10.45%였습니다. 프롬프트를 고치는 것으로는 이 문제가 사라지지 않았습니다. 그래서 AI는 제안만 하고 실제 주문 여부는 코드가 판단하도록 구조를 바꾸었습니다. 미리 검증한 종목 밖의 제안은 버리고 한 번에 바꾸는 비중이 정해 둔 한도(전체 20%, 종목당 10%p)를 넘으면 제안 전체를 거절했습니다. 프로그램이 다시 켜지더라도 같은 주문이 두 번 나가지 않도록 주문을 넣기 전에 상태를 기록하고 실제 잔고와 대조하는 장치도 넣었습니다.
가장 애를 먹은 것은 오류 메시지 하나 없이 생긴 문제였습니다. 특정 두 종목에서 3일 동안 매수 신호가 한 번도 나오지 않았는데 로그에는 아무 이상이 없었습니다. 매 판단 시점의 지표와 뉴스를 모두 저장해 두고 나중에 다시 볼 수 있는 복기 화면을 만든 뒤에야 원인이 보였습니다. 앞 순서 종목들이 증권사 API 호출 한도를 먼저 써 버려 뒤 순서 종목은 시세 데이터를 받지 못하고 있었습니다. 이 기록을 바탕으로 손절 직후 5일 동안은 다시 사지 않고 상승 추세에서만 사며 수익이 나면 절반씩 나누어 파는 규칙을 더했습니다. 손절은 35회에서 10회로 줄었습니다. 세금과 수수료를 모두 반영한 6개월 백테스트 수익률은 +33.46%로 같은 기간 S&P 500 ETF(+5.79%)보다 27.67%p 높았습니다. 약 25,500줄의 코드는 AI 코딩 에이전트를 구현 파트너로 두고 작성했으며 186개 테스트를 모두 통과하고 있습니다.

[모호한 현장 제약과 이해관계자의 언어를 하나의 동작하는 시스템으로 완성하다]
SK매직(현 SK인텔릭스)에서 데이터 사이언티스트 인턴으로 근무하며 온디바이스 AI 자율주행 공기청정기 신제품 개발 TF의 초기 멤버로 참여했습니다. 정제된 데이터도 국내외 공기질 평가 기준도 없는 백지상태였지만, 국내외 공기질 논문 수십 편을 분석해 오염원 발생 요인을 변수화하고 외부 전문 연구소와의 산학협력을 주도해 미국 EPA 기준을 응용한 인체 위해도 평가 척도를 자체 수립했습니다. 이를 토대로 몇 개 안 되는 센서 값만으로 센서 사이 거리를 따져 실내 전체의 오염 분포를 추정하는 공간 보간 모델을 개발하고 재사용 가능한 모듈형 Python 라이브러리로 패키징해 앱 개발팀에 전달했습니다. 인턴 종료 직전 실제 센서 하드웨어에 사양서와 달리 약 30분의 수치 반영 지연이 있다는 돌발 제약을 발견했을 때도, 하드웨어 전문 팀과 데이터 수집 주기를 즉시 재검토하여 30분 시차를 수학적으로 보정하는 시간 가중치 보간 시나리오를 설계해 인계했습니다. 코오롱인더스트리 산학협력 과제에서도 불균형 이진 물성을 판정하는 AutoML 분류 모듈을 단독 설계해 연속형 물성 모델과 결합했습니다. 현업 연구진의 피드백을 적극 수용해 Docker 컨테이너 기반 파이프라인으로 패키징함으로써 코오롱인더스트리 전사 도입과 국내 특허 출원을 이끌어냈습니다.

[AI의 답을 믿기 전에 외부 검증기로 먼저 확인하다]
AI 모델에게 수학 증명을 맡기면 그럴듯한 문장 뒤에 논리 비약이나 문법 오류가 숨어 있었습니다. 처음에는 프롬프트 한 번으로 풀게 하거나 기존 Agent 프레임워크를 쓰는 방법을 검토했습니다. 하지만 앞 단계의 작은 오류가 뒤 단계로 번지는 것을 막기 어려웠고 내부에서 무슨 일이 일어나는지 들여다보기도 힘들었습니다. 그래서 프레임워크 없이 순수 Python으로 Agent 루프(PFVL)를 직접 만들었습니다. 모델이 풀이를 단계별로 나누어 증명 언어인 Lean4 코드로 옮기면 Lean4 컴파일러가 이를 검사합니다. 컴파일러가 돌려준 에러 메시지를 정리해 다시 모델에게 건네고 최대 3번까지 스스로 고치게 했습니다. 그 결과 학부 순수수학 벤치마크 ProofNet에서 정확도가 한 번에 푸는 방식(4.58%)의 약 2배인 8.63%로 올랐습니다. 경시대회 벤치마크 MiniF2F에서는 대수 분야 62문제를 풀었고 올바른 코드를 만든 경우가 오류 코드보다 추론 시간이 약 57% 짧다는 것도 확인했습니다. AI를 평가하는 눈은 다른 연구에서도 길렀습니다. KCC 2024 1저자 논문에서는 LLM의 환각을 5가지 유형으로 나누고 BLEU와 ROUGE 같은 기존 지표가 어떤 유형을 놓치는지 실험으로 보였습니다. ICCV 워크숍 논문과 국내 특허 2건 공동발명에서는 모델이 데이터를 지운 것처럼 보여도 내부에 정보가 남아 있는지 측정하는 방법을 만들었습니다.

수학 증명 Agent와 실제 돈이 오가는 투자 Agent, 기업 현장의 알고리즘 배포를 거치며 하나의 원칙을 얻었습니다. AI 시스템의 신뢰는 모델 크기가 아니라 틀릴 지점을 예측 및 확인하고 그 지점을 기록과 코드로 막을 때 생긴다는 것입니다. SK AX의 AI Tech Innovation팀에서 Agent 하네스와 추론 구조를 설계하고 오류 메시지 없이 생기는 문제까지 잡아내는 Logging, Tracing, Evaluation 환경과 보안 가드레일을 만들겠습니다. 검증한 기술은 고객사의 요건과 언어로 풀어 구축과 시연까지 직접 책임지겠습니다.

#### 2. Finance Jarvis: 한국투자증권 API와 Gemini를 연결한 멀티 계좌 자동매매 및 AI 포트폴리오 Agent
* **고객사/Domain**: 개인 엔지니어링 프로젝트 (상시 운영 중) / 핀테크, AI Agent, 비동기 시스템
* **수행 기간**: 2026.09 ~ 2026.10 (프로토타입 2025.11 ~ 2025.12, 이후 전면 재설계 및 실전 운영)
* **업무 내용**:
  * 한국투자증권 OpenAPI와 Gemini API를 연결해 30분마다 시장을 판단하는 자동매매 엔진, AI 포트폴리오 Agent, 매매 복기 및 백테스트 대시보드를 하나의 비동기 시스템으로 구축하고 실전, ISA, 모의투자 3개 계좌를 각각 독립된 프로세스와 DB로 동시에 상시 운영
  * 증권사 주문 API에는 중복 주문을 막아 주는 기능이 없어 프로그램이 재시작되면 같은 주문이 두 번 나갈 위험이 있음. 주문 전에 상태를 먼저 기록하고 증권사 주문번호 및 실제 잔고와 대조하며 상황이 불확실하면 추측하지 않고 자동 주문을 멈추도록 설계
  * 여러 계좌를 동시에 돌리면 같은 계정의 실시간 시세 연결이 서로 끊기고 2분간 응답이 없으면 연결이 멈추는 문제가 발생. 실시간 연결은 주 계좌 하나만 쓰고 나머지 계좌는 주기적 조회로 체결을 확인하도록 나누었으며 30초마다 연결 상태를 확인하는 로직을 구현
  * 국내 전 종목에서 매수 후보를 자동으로 발굴하고 해외 유망 종목은 국내 상장 ETF로 대신 매매하도록 연결. AI 제안 중 검증된 후보 밖의 종목은 차단하고 전체 비중 변경 20%, 종목당 10%p 한도를 넘는 제안은 수정 없이 전체를 거절하는 규칙 기반 안전장치 구현
  * ETF를 레버리지, 테마, 지수형으로 자동 분류해 각 ETF에 영향을 주는 기업 뉴스를 연결하고 제목이 비슷한 중복 뉴스는 한 번만 분석해 API 비용 절감
  * 매 판단 시점의 지표, 뉴스, 위험 상태를 모두 저장해 다시 볼 수 있는 복기 대시보드를 구축. 3일간 특정 두 종목의 매수 신호가 오류 메시지 없이 0건이던 원인(앞 순서 종목이 API 호출 한도를 먼저 소진해 뒤 순서 종목이 시세 데이터를 받지 못함)을 찾아 해결
  * 세금, 수수료, 체결 가격 오차를 반영한 백테스트에서 손절 후 5일 재매수 금지, 상승 추세 필터, 50% 분할 익절을 도입해 손절 횟수 71.4% 감소(35회→10회) 및 6개월 누적 수익률 +33.46%(S&P 500 ETF 대비 +27.67%p, 샤프 지수 2.03, 1년 누적 +101.14%) 달성
  * 전체 설계와 실패 상황 정의는 직접 맡고 AI 코딩 에이전트(Antigravity, Claude Code)를 구현 파트너로 활용해 Python 약 25,500줄과 테스트 186개(100% 통과) 완성
* **담당 역할**: 1인 전담 (전체 설계, 비동기 백엔드와 AI 안전장치 구현, AI 코딩 에이전트 협업, 실전 계좌 운영 및 문제 해결)
* **보유/활용 Skill**: Python 3.12, FastAPI, asyncio, websockets, SQLite, Pydantic, Google Gemini API, Streamlit, Plotly, pandas, pytest, tmux, uv, Git

#### 3. Adele Ring 기반 수치 표현 학습 및 결정론적 임베딩 설계 (AOE / PFE)
* **고객사/Domain**: 학술 연구(NeurIPS, ICML) / LLM Architecture, Representation Learning, 수리인공지능
* **수행 기간**: 2024.09 ~ 2026.07
* **업무 내용**:
  * 대수정수론의 아델 환(Adele Ring) 구조를 차용해 유리수를 실수의 연속적 크기와 p진수의 정수론적 패턴으로 동시에 표현하는 학습 파라미터 없는 결정론적 수치 임베딩(AOE) 설계
  * 소형 6-layer Transformer 인코더의 표준 임베딩 레이어를 AOE로 교체하고 2D 위치 인코딩을 결합하여, 수열과 행렬의 규칙성을 추론하는 대수 조합론 6개 수학 과제에서 평균 정확도를 66%에서 92%로 대폭 향상 (NeurIPS 2025 Workshop MATH-AI 1저자 게재 및 미국 샌디에고 현장 포스터 발표)
  * 후속 연구(PFE)로 아델 조화해석학 및 Pontryagin 쌍대성을 도입하여, 슈어 보조정리(Schur's Lemma)를 통한 소수(2, 3, 5 등) 채널 간 블록 대각 독립성을 수학적으로 증명하고 채널 소거 실험으로 검증 (ICML 2026 Workshop AI4MATH 공동 1저자 게재 및 서울 현장 포스터 발표)

# 자기소개서

### 지원 동기와 본 직무를 잘 수행할 수 있다고 생각하는 이유에 대하여 본인의 보유 강점과 경험을 기반으로 기술해주세요. (자유분량)

외부 검증기를 결합한 추론 에이전트 연구부터 실전 자금이 움직이는 멀티 계좌 자율 운용 에이전트 구축, 가전 및 소재 현장의 알고리즘 배포까지 이어오며 AI가 현장에서 실패하는 지점을 시스템 구조로 통제하는 역량을 길렀습니다. 일반 상용 AI 서비스가 프롬프트 기반의 유창성에 머물 때, 기업의 실제 비즈니스를 움직이는 엔터프라이즈 AI Agent는 사소한 논리적 비약이나 통제되지 않은 오작동도 용납되지 않는 엄밀한 신뢰성과 동작 추적 가능성을 생명으로 합니다. SK AX의 AI Tech Innovation팀은 보여주기식 리서치를 지양하고, sLLM과 AI Agent 같은 코어 기술을 스스로 검증해 전사 AI 플랫폼과 고객사 현장에 내재화하며 개발부터 검증, 문서화까지 AI 활용 방식을 표준으로 세우는 실행 조직입니다. 외부 프레임워크를 맹신하지 않고 검증 루프와 안전 가드레일을 코드로 직접 구현해 온 제 엔지니어링 철학이 가장 실질적인 사업 가치로 전환될 곳이라는 확신으로 지원했습니다.

[프레임워크의 편의성에 기대지 않고 외부 검증기 연동 루프로 추론과 평가의 신뢰성을 세우다]
AI 모델이 복잡한 논리 문제를 풀 때 그럴듯한 텍스트 이면에 치명적인 논리 비약이나 문법 오류가 숨어드는 한계에 주목했습니다. 초기에는 단일 프롬프트 생성이나 상용 Agent 프레임워크 래핑을 검토했으나, 앞 단계의 사소한 추론 오류가 뒷단계로 연쇄 전파되는 현상을 막기 어렵고 내부 동작을 세밀하게 추적하기 힘들었습니다. 이에 고수준 라이브러리에 의존하지 않고 순수 Python으로 기호 정리증명 언어인 Lean4 컴파일러를 비동기로 제어하는 자가 수정 멀티턴 루프인 PFVL 프레임워크를 직접 설계했습니다. 1차 풀이를 단계별로 분해해 중간 코드를 결합하고, 외부 컴파일러가 반환하는 에러 로그를 정제해 모델에 피드백으로 재주입함으로써 최대 3회까지 스스로 코드를 교정하도록 파이프라인을 통제했습니다. 그 결과 학부 순수수학 공인 벤치마크인 ProofNet에서 단일 추론 베이스라인(4.58%) 대비 2배 가까이 높은 8.63%의 유효 증명 정확도를 달성했고, MiniF2F 경시대회 벤치마크에서도 대수 분야 62개 문제를 해결하며 유효 코드 생성 시 추론 시간이 오류 코드 대비 약 57% 짧다는 점을 정량 규명했습니다. 아울러 대형 언어모델의 질의응답 환각을 5가지 유형으로 분류해 BLEU나 ROUGE 같은 기존 평가지표의 탐지 사각지대를 실험으로 밝힌 KCC 2024 1저자 논문, 그리고 Machine Unlearning에서 출력만 바뀌고 은닉층에 지식이 남는 표면적 망각을 특징 복원 오차로 정량 검증한 ICCV 워크숍 논문 및 국내 특허 2건 공동발명 경험을 통해 Agent의 추론 품질과 보안을 다각도로 측정하는 평가 역량을 다졌습니다.

[실전 운영의 침묵하는 버그와 오작동을 상태머신과 결정론적 가드레일로 통제하다]
AI 코딩 에이전트를 개발 파트너로 지휘하여 한국투자증권 OpenAPI와 Gemini 기반의 멀티 계좌 자동매매 및 포트폴리오 에이전트를 약 25,500줄 규모로 구축하고, 비동기 환경(FastAPI, asyncio, WebSocket, SQLite)에서 실전과 절세(ISA), 모의투자 3개 계좌를 상시 운영하고 있습니다. 초기에는 LLM에 포트폴리오 조정을 폭넓게 맡겼으나 후보군 밖의 환각 티커를 제안하거나 과도한 비중 변경을 시도했고, 하락장에서 단기 반등 신호만 보고 반복 진입해 35회의 연쇄 손절과 -10.45%의 백테스트 손실을 기록했습니다. 또한 에러 로그 한 줄 없이 특정 두 종목의 매수 신호가 3일(83사이클) 내내 0건에 머무는 현상도 겪었습니다. 프롬프트 튜닝만으로는 에이전트의 오작동과 조용한 실패를 막을 수 없다고 판단해, 결정론적 코드 가드레일과 스냅샷 추적(Tracing) 환경을 전면 구축했습니다. 사전 검증된 후보군 외 티커를 차단하고 전체 회전율 20%나 종목당 비중 변화 10%p 초과 시 임의 보정 없이 제안 전체를 반려하는 안전장치를 세웠으며, 주문 의도 상태머신과 체결 즉시 실잔고 더블 체크를 도입해 중복 주문을 원천 차단했습니다. 특히 모든 판단 시점의 지표와 뉴스, 리스크 상태를 스냅샷으로 남기는 복기 대시보드를 통해 앞 순서 종목이 호출 제한 예산을 소진해 뒤쪽 종목이 분봉 데이터를 받지 못하던 기아 버그를 찾아내고 실제 API 호출 시에만 예산을 차감하도록 개선했습니다. 복기 분석을 토대로 손절 후 5일 쿨다운과 추세 필터, 50% 분할 익절 규칙을 적용해 손절 횟수를 71.4%(35회→10회) 줄였고, 실전 거래비용을 모두 차감한 6개월 백테스트에서 누적 수익률 +33.46%(동기간 S&P 500 ETF +5.79% 대비 +27.67%p 초과 수익, 샤프 지수 2.03)와 186개 단위 및 통합 테스트 상시 통과를 달성했습니다.

[모호한 현장 제약과 이해관계자의 언어를 하나의 동작하는 시스템으로 완성하다]
SK매직(현 SK인텔릭스)에서 데이터 사이언티스트 인턴으로 근무하며 온디바이스 AI 자율주행 공기청정기 신제품 개발 TF의 초기 멤버로 참여했습니다. 정제된 데이터도 국내외 공기질 평가 기준도 없는 백지상태였지만, 국내외 공기질 논문 수십 편을 분석해 오염원 발생 요인을 변수화하고 외부 전문 연구소와의 산학협력을 주도해 미국 EPA 기준을 응용한 인체 위해도 평가 척도를 자체 수립했습니다. 이를 바탕으로 한정된 센서 데이터로 실내 전체 오염 분포를 추정하는 역거리가중법 공간 보간 모델을 개발해 재사용 가능한 모듈형 Python 라이브러리로 앱 개발팀에 전달했습니다. 인턴 종료 직전 실제 센서 하드웨어에 사양서와 달리 약 30분의 수치 반영 지연이 있다는 돌발 제약을 발견했을 때도, 하드웨어팀과 데이터 수집 주기를 즉시 재검토하여 30분 시차를 수학적으로 보정하는 시간 가중치 보간 시나리오를 설계해 문서로 정리하여 인계했습니다. 코오롱인더스트리 산학협력 과제에서도 불균형 이진 물성을 판정하는 AutoML 분류 모듈을 단독 설계해 연속형 물성 모델과 결합하고, 현업 연구진의 피드백을 반영해 Docker 컨테이너 기반 파이프라인으로 패키징함으로써 코오롱인더스트리 전사 도입과 국내 특허 출원을 이끌어냈습니다.

연구실의 추론 검증 루프부터 실전 자금이 도는 비동기 에이전트 운영, 기업 현장의 알고리즘 패키징까지 모든 경험이 가르쳐준 원칙은 명확합니다. AI 시스템의 실질적 가치는 모델의 크기가 아니라, 데이터가 깨지는 지점과 실패 모드를 먼저 정의하고 이를 추적 가능한 로그와 결정론적 코드로 통제할 때 비로소 완성된다는 점입니다. SK AX AI Tech Innovation팀에 합류하여 Agent Harness와 추론 파이프라인을 견고하게 설계하고, 현장의 침묵하는 오류까지 실시간으로 포착하는 Logging, Tracing, Evaluation 환경과 보안 가드레일을 구축하겠습니다. 검증된 기술을 사업 현장의 언어로 끝까지 완결 지어 고객사와 전사 구성원이 의심 없이 믿고 쓸 수 있는 엔터프라이즈 Agent 표준을 만들어 가겠습니다.

#### 2. Finance Jarvis: KIS OpenAPI 및 Gemini 기반 멀티 계좌 자동매매 엔진과 AI 포트폴리오 에이전트 구축
* **고객사/Domain**: 개인 엔지니어링 프로젝트 (상시 운영 중) / 핀테크, AI Agent, 비동기 분산 제어 시스템
* **수행 기간**: 2026.09 ~ 2026.10 (프로토타입 2025.11 ~ 2025.12, 아키텍처 전면 재설계 및 실전 운영)
* **업무 내용**:
  * 한국투자증권(KIS) OpenAPI(REST 및 실시간 WebSocket)와 Gemini API를 결합하여, 30분 주기 스윙 및 적립식 하이브리드 자동매매 엔진, AI 포트폴리오 에이전트, 미국장 시그널 룸, 매매 복기 및 백테스팅 대시보드를 통합 구축하고 실전, ISA 절세, 모의투자 3개 계좌 멀티 프로필을 독립 프로세스(tmux, flock)와 독립 DB로 동시 상시 운영
  * 멱등성 키를 지원하지 않는 증권사 주문 API 환경에서 프로세스 재시작 시 이중 주문을 방지하기 위해 주문 의도 상태머신(FSM) 선기록, 채번 주문번호 1:1 대조 및 퍼지 매칭, 체결 즉시 실잔고 더블 체크 파이프라인을 구현하고 모호한 경우 추측 대신 자동 주문을 잠그는 상태 제어 설계
  * 복수 계좌 동시 구동 시 발생하는 동일 계정 웹소켓 세션 충돌과 유휴 시간(120초 무응답) 데드락을 해결하기 위해 주 계좌만 웹소켓을 연결하고 보조 계좌는 REST 체결 대조 모드로 분리했으며, 30초 주기의 자체 하트비트 응답 로직과 손절 우선 통과 게이트 구현
  * KOSPI 및 KOSDAQ 전 종목 동적 발굴과 해외 유망 종목의 국내 상장 대체 ETF 자동 매핑(Proxy Trading) 파이프라인을 구축하고, 사전 검증된 후보군 외 환각 티커 차단 및 회전율 20%, 종목당 비중 변화 10%p 초과 시 임의 보정 없이 제안 전체를 반려하는 결정론적 가드레일 구현
  * 단일 종목 레버리지, 테마, 광범위 지수 3계층으로 ETF를 자동 분류해 기초자산 및 핵심 앵커 기업의 뉴스 감성과 월가 컨센서스를 라우팅하는 자기학습 캐시 매퍼와 제목 자카드 유사도(0.65 이상) 기반 중복 뉴스 교차 캐싱으로 API 비용 최적화

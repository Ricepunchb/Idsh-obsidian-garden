
# 자기소개서
## 1번. 직무 전문성 개발 경험. 지원 분야의 전문성을 갖추기 위해 본인이 노력한 차별화된 활동과 경험에 대해 서술해 주세요. (500자 이상 1000자까지)
- 전문성을 키우고자 한 구체적인 영역(예.통계 분석) / 목표와 학습·실행 과정 / 전문성의 향상을 확인할 수 있는 결과나 근거가 잘 드러나도록 서술해 주세요. 공동 활동의 경우 본인의 역할과 기여를 구체적으로 설명해 주세요.

[이진 판정 물성과 복합 배합 제약을 풀어 최적 조성비 추천을 현장화하다]
코오롱인더스트리 산학 과제와 후속 프로젝트를 수행하며, 공정과 R&D 현장의 제약을 분석해 최적 조성비를 추천하는 예측 및 최적화 모델링 역량을 길렀습니다.

3인 산학 과제에서는 실험 비용 절감을 위해 베이지안 최적화 기반의 신소재 조성비 추천 파이프라인을 개발했습니다. 현업 데이터를 분석한 결과 목표 물성 상당수가 합격과 불합격의 이진 판정 값이어서 단일 회귀 모델로는 다룰 수 없었습니다. 이에 팀원이 맡은 연속형 예측용 Gaussian Process와 결합하도록, 여러 ML 분류 모델을 자동 탐색해 묶는 AutoML 앙상블 모듈을 단독 설계하고 구현했습니다. 소량 불균형 데이터에서 정확한 합격 확률을 얻고자 CatBoost와 Random Forest 등의 결정 경계 특성과 확률 보정 기법을 문헌으로 학습했습니다. 표본이 적어 검증이 어렵자 유사 포맷 공개 데이터로 사전 검증한 뒤 적용했고, 클래스 가중치와 임곗값을 조정해 예측 확률이 실제 성공 확률에 수렴하게 했습니다. 조성비 합이 100%가 되어야 하는 배합 제약에서 무작위 생성 후 조건 미달 표본을 버리는 기존 샘플링의 병목은, 제약 공간 내 균일 표본을 즉시 생성하는 DRS 알고리즘으로 해결했습니다. 팀 Git 코드 리뷰와 Docker 패키징을 거쳐 인계한 결과, 특허 출원(10-2025-0195253)과 전사 도입으로 이어졌습니다.

인계 후에는 추천이 한 점에만 몰려 대안 레시피가 부족한 문제를 발견하고 후속 프로젝트를 수행했습니다. 단일 최적점 대신 목표 물성 구간 전체를 탐색하도록 후보 탐색 수식(획득함수)에 양방향 구간 제약을 걸고 3,570회 실험을 수행해, 서로 다른 유효 조성비를 베이스라인 대비 1.3~2.2배(최대 7.2배) 더 확보했습니다. 현장 데이터와 제약을 수리 모델로 정의하고 검증한 경험으로 SK이노베이션의 공정 및 R&D 예측과 최적화 모델 개발에 기여하겠습니다.

## 2번. 틀을 깨는 과감한 실행/도전 경험. 익숙한 환경이나 방식에서 벗어나 새로운 분야에 도전하거나, 스스로 도전적인 목표를 세워 실행한 경험을 서술해 주세요. (500자 이상 1000자까지)
- 도전의 계기와 목표 / 구체적 실행 과정 / 과정에서 겪은 어려움과 이를 해결하기 위한 노력 / 결과와 배운 점이 잘 드러나도록 서술해 주세요.

[모델을 키우기 전에 숫자를 받아들이는 입력 구조부터 다시 설계하다]
딥러닝 모델과 AI 에이전트의 수치 환각을 근본부터 해결하고자, 표준 임베딩을 걷어내고 대수적 수치 임베딩을 직접 설계해 LLM 학습까지 확장한 경험이 있습니다. 기존 LLM 토크나이저는 3.14를 "3 / . / 14"처럼 분절 인식해 숫자 간 연산 구조를 잃고 수치 환각을 일으킵니다. 모델 크기만 키우거나 프롬프트로 우회하는 익숙한 방식에서 벗어나, 유리수를 실수 크기와 소수(2, 3, 5 등)별 진수 패턴으로 동시에 표현하는 대수정수론 Adele Ring을 딥러닝 입력 표현으로 이식하는 목표를 세웠습니다.

무한한 대수 구조를 유한한 GPU 텐서로 옮기자 정밀도와 연산량이 충돌하는 난관에 부딪혔으나, 관련 연구를 조사해 유한 개 소수 진수와 N자리로 압축하되 사칙연산 성질은 유지하도록 이산화한 절충안과 2차원 위치 인코딩을 도출했습니다. 그 결과 6-layer Transformer에서 수열과 행렬의 규칙성을 추론하는 6개 수학 과제 평균 정확도를 66%에서 92%(특정 과제 100%)로 높여 NeurIPS 2025 MATH-AI 워크숍에 1저자로 발표했습니다. 나아가 각 진수 표현이 서로 간섭하지 않고 독립적 특징을 학습함을 슈어 보조정리로 증명하고 실증해 ICML 2026 AI4MATH 워크숍에 공동 1저자로 발표했습니다.

현재는 소형 모델을 넘어 LLM이 정형 데이터와 사칙연산, 수학 문제를 더 잘 푸는지 검증하는 사전학습과 사후학습을 진행 중입니다. GPT2와 Llama2의 토크나이저와 임베딩 레이어를 수정해 숫자를 특수 토큰으로 분리하고 대수적 임베딩을 주입했습니다. 토크나이저 변경으로 위치 인코딩과 손실 함수까지 연쇄 수정해야 하는 문제를 직접 해결하며, 이론이 실제 시스템에서 성립하는 조건을 실험으로 확인하고 절충하는 습관을 갖췄습니다. 원인을 구조 밑바닥까지 내려가 해결해 본 경험으로 SK이노베이션 AI 에이전트의 응답 품질과 근거성, 안정성을 높이겠습니다.

## 3번. AI 활용 문제 해결 경험. AI를 활용하여 문제를 해결하거나 기존 방식보다 더 나은 결과를 만들어낸 경험에 대해 서술해 주세요. (500자 이상 1000자까지)
- 해결하려던 문제 / 활용한 AI 도구·기술과 활용 방식 / 본인이 직접 수행한 판단·수정·보완 / 결과의 정확성이나 유용성을 확인한 과정 / 최종 결과와 개선 효과가 잘 드러나도록 서술해 주세요.
- AI 서비스를 단순 질의응답 형태로 활용한 경험은 작성을 지양해 주세요.

[막연한 지시 대신 구체적 규칙을 주입해 자율 매매 에이전트를 완성하다]
기존 주식 분석 프로토타입은 매수와 매도 신호만 띄워 뉴스 확인과 비중 조절, 주문을 직접 해야 했습니다. 이를 자동화하고자 신호 생성부터 뉴스 분석, 리밸런싱, 자동매매까지 수행하는 자율 에이전트 Finance Jarvis를 구축했습니다. Antigravity와 Claude Code에 아키텍처 명세와 상태 전이 규칙을 주입하는 루프 엔지니어링으로 3주 만에 FastAPI, SQLite, asyncio 기반 약 1.5만 줄의 시스템을 완성했습니다. 내부에는 Gemini 에이전트를 탑재해 후보 발굴과 뉴스 분석, 리밸런싱 제안, 한국투자증권 OpenAPI 자동 매매가 맞물려 돌아가게 했습니다.

구현은 코딩 AI와 협업했지만 자금이 오가는 안전 규칙은 직접 설계했습니다. AI에만 맡기면 과한 비중 변경을 제안하거나 API 호출 제한에 걸렸기 때문입니다. 이에 전체 자산의 20%나 종목당 비중을 10%p 넘게 바꾸려 하면 제안을 반려하는 안전장치를 코드로 강제했습니다. 코딩 AI가 놓친 호출 제한은 1.2초 간격 제어 로직으로 막았고, 주문 의도를 DB에 선기록한 뒤 재기동 시 체결 내역과 대조해 불확실하면 추가 주문을 멈추는 상태 관리 로직도 구현했습니다.

정확성은 132개 테스트(100% 통과)와 모의투자로 점검했고, 외부 지표 라이브러리의 수식 오류도 수동 대조로 잡아내 교체했습니다. 수수료 0.18%와 슬리피지 0.05%를 반영한 백테스터로 검증한 결과, 초기 전략은 하락장 반복 진입으로 연쇄 손절이 나며 -10.45%를 기록했습니다. 복기 대시보드로 원인을 찾은 뒤 추세 필터와 5일 재진입 금지, 50% 분할 익절을 보완해 6개월 백테스트 손절을 35회에서 10회로 줄였고, S&P 500 ETF(+5.79%) 대비 27.67%p 높은 +33.46% 수익률을 달성했습니다. AI에 구체적 규칙을 주고 실데이터로 검증한 경험을 AX단의 업무 자동화 에이전트에 적용하겠습니다.

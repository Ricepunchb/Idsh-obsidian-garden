# Career Summary

## 1. 지원 동기 (Motivation for the Application)

글로벌 빅테크들이 거대 GPU 클러스터를 동원한 물량 투입에 의존할 때, 퓨리오사AI는 실리콘(RNGD)과 컴파일러부터 그 위에서 구동될 독자 LLM까지 하나의 유기체로 함께 설계하며 추론 시대의 비용과 에너지 병목을 아키텍처 수준에서 해결하고 있습니다. 어떤 수리적 구조를 선택하느냐에 따라 하드웨어가 실제로 처리하는 텐서 연산의 밀도와 메모리 이동 효율이 근본적으로 달라집니다. 따라서 고성능 NPU의 잠재력을 끝까지 끌어내려면 하드웨어의 연산 특성을 깊이 이해하고, 이에 맞춰 모델의 표현 구조와 학습 파이프라인을 밑바닥부터 다시 설계하는 연구가 필수적입니다.

저는 파라미터를 무작정 키우는 대신 대수정수론과 조화해석학의 원리로 신경망의 내부 표현 공간과 선형 연산 구조를 재설계하고, 이를 오픈소스 LLM에 이식해 처음부터 사전학습하는 연구를 주도해 왔습니다. 하드웨어와 알고리즘, 그리고 사후학습 시스템을 한 지붕 아래에서 통합 설계하는 퓨리오사AI의 AI Research Part야말로 제 연구 철학이 가장 큰 파급력을 낼 수 있는 무대입니다. 입사 후 퓨리오사AI의 텐서 연산 구조에 최적화된 독자 LLM 아키텍처를 설계하고 훈련하며, 추론 비중이 큰 비동기 강화학습 사후학습 파이프라인과 에이전틱 모델을 고도화하는 데 기여하고 싶습니다.

경험적으로 쌓아 올린 기존 트랜스포머의 비효율을 수학적으로 재정의하고 개선하는 연구에 집중합니다. 임의의 토큰 분절로 인해 대수적 구조가 깨지거나 거대한 밀집 행렬 연산에 의존하는 한계를 넘고자, 학습 파라미터 없이 수의 성질을 보존하는 텐서 구조와 채널별 블록 대각 독립 분해를 신경망에 이식해 왔습니다. 파라미터와 불필요한 연산량을 줄이면서도 표현력과 병렬 텐서 연산 효율을 높이는 아키텍처를 설계하고, 토크나이저와 레이어 내부를 직접 개조해 밑바닥부터 사전학습하는 연구를 지향합니다.

[결정론적 통제와 비동기 파이프라인을 결합한 에이전틱 시스템]

## 3. 주요 경험 (Experience)

[파라미터 추가 없이 대수적 구조를 이식하고 오픈소스 LLM 내부를 개조해 사전학습하다]
LLM 토크나이저가 3.14를 "3", ".", "14"처럼 임의로 쪼개 인식해 대수적 구조가 깨지고 수치 환각이 발생하는 문제를 해결하고자, 모델이 숫자를 받아들이는 표현 체계 자체를 수학적으로 재설계했습니다. 1단계 연구에서는 유리수를 실수의 크기 정보와 소수(2, 3, 5 등)별 진법 패턴으로 동시에 표현하는 대수정수론의 Adele Ring 구조를 도입했습니다. 6-layer Transformer 인코더의 표준 임베딩 레이어를 학습 파라미터가 전혀 없는 결정론적 텐서(AOE)와 2차원 위치 인코딩으로 전면 교체하여, 파라미터 수를 줄이면서도 수열과 행렬의 규칙성을 추론하는 6개 수학 과제(13개 실험 세팅) 평균 정확도를 66%에서 92%로 끌어올렸고 특정 난제(Weaving Patterns)에서 최초 100%를 달성해 NeurIPS 2025 워크숍(MATH-AI)에 1저자로 발표했습니다.

2단계 연구에서는 이 구조가 작동하는 수학적 원리를 규명하고자 정수를 소수별 복소평면 단위원 위상 회전으로 인코딩하는 Prime Fourier Embeddings(PFE)를 설계했습니다. 이동 등변 성질을 만족하는 모든 선형사상이 소수 채널별로 완전히 독립된 블록 대각 구조로 분해되어야 함을 슈어 보조정리로 증명하여, 거대한 밀집 행렬 연산을 독립적인 작은 블록 단위의 텐서 연산으로 쪼갤 수 있음을 수학적으로 보증했습니다. 모듈러 연산 실험에서 과제 관련 소수 채널 제거 시에만 정확도가 급감하는 채널 선택성을 입증해 ICML 2026 워크숍(AI4MATH)에 공동 1저자로 발표했습니다.

현재는 고려대학교 산학협력단 기초과학연구원에서 상근 연구원으로서 검증된 수리적 구조를 nanoGPT와 Llama 등 기성 오픈소스 LLM 아키텍처에 직접 이식하여 처음부터 사전학습하는 3단계 연구를 주도하고 있습니다. 토크나이저와 임베딩 레이어 코드를 직접 수정해 입력 텍스트에서 숫자를 별도의 특수 토큰으로 분리하고 AOE 및 PFE 인코더를 거치도록 구현했습니다. 수치 안정성을 높이는 커스텀 손실 함수와 Muon 옵티마이저로 사전학습 실험을 진행 중이며, 출력단에 전용 디코드 헤드를 두어 마지막 은닉 상태를 중국인의 나머지 정리로 역산하거나 낮은 자릿수부터 복원하는 구조를 실험하며 파라미터 증량 없이 추론 정확도와 토큰 연산 효율을 확보하고 있습니다.

[메모리 대역폭 병목을 돌파해 제한된 자원에서 추론 효율을 극대화하다]
파라미터 3B 미만, 단일 GPU(RTX 3090) 제약 환경에서 일상 사진 기반 5지선다 추론 문제를 푸는 온디바이스 VLM을 단독으로 설계하고 훈련했습니다. 초기에는 단일 소형 VLM에 시각 인지와 복합 추론을 동시에 학습시켰으나, 작은 파라미터 용량 안에서 두 과업이 충돌하며 모달리티 정렬이 무너지고 추론 성능이 급락했습니다. 이를 해결하기 위해 시각 묘사(KOSMOS-2, 1.95B)와 언어 추론(Flan-T5, 0.78B)을 직렬 분리한 총 2.74B 규모의 Two-Stage 파이프라인으로 전환하고, 4-bit QLoRA와 난이도 순 커리큘럼 러닝을 결합해 양자화 학습의 수렴 안정성을 확보했습니다. 특히 추론 시 발생하는 GPU HBM과 SRAM 간의 입출력 대역폭 병목을 해소하고자 Flash Attention v2를 적용하고, PyTorch 2.0의 torch.compile 커널 퓨전으로 레이어 간 데이터 이동 오버헤드를 최소화해 베이스라인 대비 메모리 사용량을 약 75% 절감하고 추론 속도를 1.2배 향상시키며 전체 23위(상위 9%)로 본선에 진출했습니다.

[AI 에이전트 협업과 결정론적 상태 관리로 비동기 제어 파이프라인을 구축하다]
외부 API 도구 호출과 실시간 스트리밍 처리가 맞물리는 비동기 에이전트 시스템의 제어 역량을 다지고자, Claude Code 및 Antigravity 등 AI 코딩 에이전트를 오케스트레이션하여 3주 동안 FastAPI, asyncio, 웹소켓, SQLite 기반의 비동기 시스템 약 1.5만 줄을 구축하고 132개 단위 및 통합 테스트를 100% 통과시켰습니다. 언어 모델의 환각이나 네트워크 지연이 시스템 전체의 오류로 번지는 것을 막기 위해 프롬프트에만 의존하지 않고 코드 레벨의 결정론적 안전장치를 설계했습니다. 중복 실행 방지 키가 없는 외부 API의 한계를 극복하고자 실행 전 의도를 데이터베이스에 선기록하고 재시작 시 실제 처리 내역과 대조해 불확실한 상태에서는 즉시 실행을 멈추는 상태 관리 로직을 구현했으며, AI 에이전트의 제안이 허용 임계치를 넘기면 보정 없이 전체를 반려하는 가드레일을 결합해 비동기 도구 호출 파이프라인의 결함 내성을 확립했습니다.

[외부 컴파일러 피드백 루프와 추론 시간 분석으로 에이전틱 사후학습의 기반을 다지다]
자연어 수학 문제를 형식 증명 언어인 Lean4 코드로 변환할 때 초반의 사소한 구문 오류가 뒷단 전체로 증폭되는 문제를 해결하기 위해, 외부 컴파일러 검증을 결합한 에이전트 프레임워크(PFVL)를 설계하고 구현했습니다. 자연어 풀이를 논리 단위로 분해해 단계별로 코드를 결합하고, 외부 Lean4 컴파일러(v4.20.0)가 반환하는 에러 로그를 파싱해 최대 3회까지 스스로 코드를 교정하는 루프를 구축했습니다. 컴파일러 프로세스와의 세밀한 동기화를 위해 무거운 외부 프레임워크를 배제하고 순수 Python으로 제어기를 직접 작성하여, 순수수학 벤치마크 ProofNet(371문항)에서 제로샷 베이스라인(4.58%) 대비 정확도를 8.63%로 약 2배 향상시키고 MiniF2F 대수 파트에서 62문항을 해결했습니다. 아울러 유효한 증명 코드를 생성한 추론 시간이 실패 케이스 대비 약 57% 짧다는 사실을 정량 규명하여, 대규모 추론이 동반되는 사후학습 파이프라인에서 불필요한 긴 추론을 조기 판별할 수 있는 근거를 확인했습니다.

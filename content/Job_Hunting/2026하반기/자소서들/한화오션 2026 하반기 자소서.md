# 자기소개서
## 1번. 한화오션에 지원하게 된 동기와 한화오션이 'Global Ocean Solution Provider'로 도약하는데 본인이 기여할 수 있는 바를 작성해 주세요. (1000자)
AX를 좌우하는 축은 결국 두 가지라고 생각합니다. 현장의 데이터를 신뢰할 수 있는 자산으로 구조화하는 일과, 그 자산을 바탕으로 실제 판단과 업무를 대신하는 일입니다. 저는 이 두 축을 각각 실제 현장에서 경험했습니다. SK매직 데이터 사이언티스트 인턴 시절 자율주행 공기청정기 신제품 TF에 초기 멤버로 합류해, 정제된 데이터도 판단 기준도 없는 완전한 제로베이스 상태에서 보조 공기질 센서 최적 배치 문제를 맡았습니다. 국내외 실내 공기질 논문을 탐독해 오염원 변수를 정리하고 서경대, 연세대 환경 연구소와 협력해 인체 위해도 평가 척도를 자체 개발했으며, 한정된 센서 데이터로 실내 전체 공기질을 예측하는 IDW 공간보간 모델을 개발해 재사용 가능한 Python 라이브러리로 구축, 앱 개발팀에 인계했습니다. 모델을 개발하는 데서 그치지 않고 현업 부서가 실제로 쓸 수 있는 형태로 전달하는 과정이었습니다. 코오롱 인더스트리와의 산학협력에서는 배합비, 비용, 물성 조건이 복잡하게 얽힌 소재 실험을 최적화하는 시스템을 팀과 함께 개발했습니다. 연속형 물성은 Gaussian Process, Pass/Fail 이진 판정은 AutoML로 나누는 구조에서 AutoML 모듈을 전담했고, 현장 계량 단위까지 반영한 제약 만족 샘플링 알고리즘을 도입해 병목을 제거했습니다. 이 시스템은 Docker 기반으로 패키징해 특허 출원과 코오롱 인더스트리 전사 도입까지 이어졌습니다. 한화오션이 그리는 스마트 야드는 상선, 해양, 특수선이라는 이질적인 사업영역에서 쏟아지는 방대하고 비정형적인 현장 데이터를 다뤄야 한다는 점에서, 제가 풀어본 문제의 확장판이라고 생각합니다. 입사 후에는 업무 프로세스를 분석해 AI 전환 과제를 발굴하고, 데이터 파이프라인과 거버넌스 체계를 구축하며 Dashboard 같은 업무용 디지털 솔루션으로 현업의 의사결정을 지원해, 한화오션이 Global Ocean Solution Provider로 도약하는 데 기여하겠습니다.

## 2번. 본인의 성격 상 장·단점을 기술하고, 업무 환경 또는 단체 활동에서 어떻게 발현되는지 알려주세요. (1000자)
제 장점은 묵묵함입니다. 함께 연구했던 랩실 선배들이 졸업 후 논문 양장본에 공통으로 남긴 평가가 "조용하고 묵묵하게 항상 할 일을 해내는 사람"이었을 정도로, 말보다 결과로 증명하는 방식을 선호합니다. 석사 과정 중 이론은 맞았는데 실험 결과가 한 달 가까이 진전이 없어 지도교수님께 속도가 느리다는 질타를 받은 적이 있습니다. 그때도 감정적으로 대응하기보다 실험을 묵묵히 이어가며 원인을 하나씩 배제해 병목 지점을 데이터로 특정했고, 중간발표에서 이를 객관적으로 설명해 방향을 인정받아 결국 논문 게재까지 마무리했습니다. 같은 성향은 단체 활동에서 협업 방식으로도 드러납니다. 프로젝트를 함께하던 친한 랩실 동기와 밤샘 작업을 대하는 방식이 달라 코드 팔로우업과 가독성을 두고 갈등을 겪은 적이 있는데, 감정을 배제하고 1:1로 대화해 모듈별 역할을 명확히 나누고 매일 코드 리뷰와 싱크 회의를 규칙으로 도입해 갈등을 해소했습니다. 다만 이런 몰입이 지나쳐 개인 생활 리듬까지 흔들린 시기도 있었습니다. 석사 초반에는 연구실 문을 가장 먼저 열고 가장 늦게 닫는 날이 이어지며 체력과 집중력이 오히려 떨어지는 비효율을 겪었습니다. 연구도 단거리가 아니라 장기 마라톤이라는 점을 깨닫고, 이후에는 하루 단위로 목표를 쪼개 관리하고 점심 후 스쿼트 같은 짧은 루틴을 규칙적으로 넣어 체력과 집중력을 관리하는 습관을 만들었습니다. 여러 부서와 장기간 협업해야 하는 AX 업무에서도, 몰입할 때는 깊게 파고들되 스스로를 관리해 꾸준히 성과를 내는 방식으로 기여하겠습니다.

## 3번. 해당 직무를 수행하는데 가장 중요한 역량은 무엇이고, 그 역량을 준비하기 위해 어떤 노력을 해 오셨는지 알려주세요. (1000자)
AX 직무를 수행하는데 가장 중요한 역량은 이론이 아니라 현장의 제약 조건을 반영해 실제로 배포 가능한 데이터 기반 AI 시스템으로 완성하는 능력이라고 생각합니다. 이 역량은 코오롱 인더스트리 산학협력 과제에서 8개월에 걸쳐 직접 준비했습니다. 초기에는 단일 Gaussian Process와 Rejection Sampling만으로 설계했지만, 현업 피드백을 통해 실험 결과 상당수가 연속값이 아니라 Pass/Fail 이진 판정으로 나온다는 점과 배합비, 총량 결합 제약에서 Rejection Sampling이 심각한 속도 병목을 일으킨다는 점을 확인했습니다. 이에 연속형 물성은 Gaussian Process, 이진 판정은 AutoML로 분리하는 Two-Track 구조로 다시 설계하고, 제약공간 안에서 곧바로 균일한 샘플을 생성하는 DRS 샘플링으로 전면 교체해 병목을 제거했습니다. 이후 이산형, 범주형 변수와 현장 계량 단위(5% 스텝 등)까지 반영해 실사용 가능한 배합비를 추천하도록 다듬고, Python 3.12와 Docker 기반 모듈형 파이프라인으로 패키징해 Github 저장소와 운영 매뉴얼까지 현업에 인계했습니다. 이 과정에서 AutoML 모듈은 제가 단독으로 설계하고 구현했습니다. 대수적 정수론 기반 수치 임베딩 연구로 NeurIPS, ICML 워크숍에 논문을 게재하며 최신 연구를 실제 구조 설계에 적용해본 경험도 이런 역량의 연장선에 있습니다. 여기에 더해 Oracle Cloud Infrastructure에서 컴퓨트 인스턴스를 직접 프로비저닝하고 Docker Compose로 서비스를 배포하고 운영하며, 클라우드 인스턴스와 컨테이너 오케스트레이션의 기본기도 개인적으로 다져왔습니다. 한화오션에 입사해서도 현장 부서의 요구가 바뀔 때마다 구조를 다듬어 실제로 쓰이는 데이터 기반 AI 시스템을 완성하는 방식으로 기여하겠습니다.

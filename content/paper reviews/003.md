# Nemotron Elastic: Towards Efficient Many-in-One Reasoning LLMs
- [Hugging Face 모델 페이지](https://huggingface.co/nvidia/Nemotron-Elastic-12B)
## Abstract
- 마트료시카 인형처럼 큰 AI 모델 안에 작은 모델들을 겹겹이 넣어서, 한 번의 학습으로 여러 크기의 모델을 동시에 만듦
- 기존 방식은 각 크기의 모델마다 따로따로 학습을 해야 했음
	- 엄청난 시간과 비용이 듦
- 이 논문에서는 6,9,12B 모델을 Nested 구조로 한 번에 학습
	- 작은 모델들이 큰 모델의 일부를 그대로 사용하며
	- 학습 이후 추가 학습 없이 원하는 크기를 바로 추출(Zero-shot extraction) 할 수 있음
- 효율성
	- 기존 대비 학습 비용을 360배 절감
	- 110B 토큰만 사용하여 기존 압축 기법 대비 7배 효율적
	- 3개 모델(위에서 말한 6, 9, 12B)을 저장해도 1개 모델 크기만 필요
	- 이러면서도 성능은 기존과 동등하거나 더 좋아짐
- 메소드
	- 짦은 컨텍스트에서 긴 컨텍스트로 단계적 학습
	- 라우터를 통해 각 상황에 맞는 최적의 모델 구조를 자동으로 선택
	- Mamba + Attention 결합으로 효율성 극대화
- 실용적으로는 상황에 맞춰 즉시 모델을 전환할 수 있다는 의미가 있음
## Introduction
- 최신 LLM은 파라미터 규모를 키우고 성능을 높이고 있지만 엄청난 비용을 소모하고 있는 중
	- Llama 3.1 같은 경우 8B, 40B, 405B를 배포했는데, 이를 구축하기 위해 각 모델은 별도로 훈련 됨
	- Pruning이나 Knowledge Distillation 같은 효율성 관련 기술이 존재하지만 이 방법들도 수천억 토큰 분량의 재훈련이 필요하긴 함
- 위 이슈 관련해서 최근 두 흐름이 있음
	- 1. 하이브리드 아키텍처
		- Attention 메커니즘에 [Mamba] 같은 [SSM]을 결합한 구조
		- KV-Cache 요구량을 줄이고 Linear complexity로 시퀀스를 처리하면서 정확도가 높음
	- 2. 추론 모델
		- base, instruction-tuned 모델에서 추론 중심 모델로 옮겨가는 중
		- 최근 LLM은 복잡한 문제 해결에 초점을 맞춰 긴 CoT를 할 수 있음
		- 다만 토큰 예산이 크게 필요하고 기존 compression 기법은 이 추론 과정을 충분히 받쳐주지 못함
### Nemotron Elastic
- 이 새로운 프레임 워크를 제안
- 하나의 부모 모델 안에 여러 Nested 서브모델을 내장해 요구사항에 맞게 각 서브모델이 즉시 추출될 수 있도록 설계
- 핵심 요소는 End-to-End 라우터
- 라우터는 요구에 맞춰 어떤 서브모델만 활성화 할지 자동 결정
- Reasoning 모델로 학습시키기 위해 Two-stage 커리큘럼 학습 도입
	1. 짧은 컨텍스트에서 라우터를 안정화시켜 기본적인 구조 선택을 학습
	2. 긴 컨텍스트를 사용해 Reasoning에 필요한 Long term 의존성을 모델이 학습
- 효율성 측면에서 4가지 요소를 달성
	1. 중요도 기반 구성요소 순위화
	2. Knowledge distillation에서 teacher 모델을 고정시켜 여러 서브모델 동시 최적화
	3. 라우터 안정화와 긴 컨텍스트 reasoning을 차례로 학습
	4. 라우터가 실제 작업 난이도에 따라 어떤 아키텍처를 선택할지 학습. 사후 별도 검색이나 휴리스틱 필요 없음
### Main Contributions
1. 최초의 reasoning 특화 Elastic 아키텍처
	- 하나의 12B 모델 안에 9B, 6B 모델을 nest해서 동시 학습
2. 깊이 조절
	- normalized MSE기반 레이어 제거
	- single-shot이나 perplexity 기반 메소드보다 좋았음
3. Knowledge Distillation 활용
4. 학습 비용 절감
5. 메모리 효율적 학습
6. Heterogeneous(층별 맞춤 압축)
